# Builder Assistant 路线图

状态以源码、离线测试和平台验收分别记录；Windows编译不代表Android7723已验证。当前版本v0.22.0，SCIE-Port为独立工程，不在本路线图中。

## 已实现并纳入离线/构建验证

- 最小加载、独立工具900–904、环境ABI检查与netmod打包。
- 63种原版材料、精细DATA、四向旋转、区域复制和参数化建筑生成。
- schema1/2/3导入，10种结构块家具模板；新保存统一schema3。
- 903管理窗口、剪贴板导入、中文名称、显式保存、重名编号、本地载入/刷新/确认删除。
- 只读落点范围、地面占地、原点、作者前向、Y高度和冲突标记；旋转、升降、重新点地和确认。
- 预检、区块有限等待、房主权限、每事务10000格/每轴64格/每批32格，分批取消、回滚与撤销。
- 确认前地形快照复核；地形变化后更新预览并要求再次确认。

当前规范入口：[BLUEPRINT-SPEC.md](BLUEPRINT-SPEC.md)。设备步骤与验证结果：[v0.22记录](BUILDER-BLUEPRINT-0.22.0.md)。
