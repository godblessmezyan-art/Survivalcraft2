# Builder Assistant 统一蓝图生成规范 v0.22.0

本规范定义 AI 新生成和游戏新保存的交换格式。解析器以 `BlueprintJson` / `BlueprintImportService` 为准，旧 schema 1/2 文件仍可导入，不改变旧坐标、DATA 和家具外观。新输出统一 schema 3；不需要 schema 4。

## 格式和限额

- 输出单个严格 JSON 对象，UTF-8；不包含 Markdown 围栏、注释、尾随逗号、脚本或解释。
- `schemaVersion`：新输出固定整数 `3`；`kind`：固定 `builderassistant.blueprint`；`name`：非空显示名称，可中文。
- `cells`：必填数组。每格为 `{ "x":0, "y":0, "z":0, "key":"PlanksBlock", "f":"cube", "d":0 }`。
- `x/y/z` 是相对整数坐标，建议从 0 开始，限制在 ±1000000 以内，不能重复。导入时整体平移，使结构与家具联合最小角为 `(0,0,0)`。
- `key` 只能使用 [能力清单](blueprint-block-reference.md) 的具体类型名或已列出的逻辑材料键。推荐具体类型名。大小写严格匹配，不写数字方块 ID。
- `f` 默认为 `cube`，非立方方块必须显式写实际族：`stairs/slab/fence/door/log/ladder/torch`。`d` 默认为 0；必须是该类型的合法 DATA，不能仅根据范围猜测，精确集合见 [机器矩阵](blueprint-block-capabilities.json) 的 `allowedData`。
- 推荐 cell 使用内联 `key`。也可提供 `materials:[{"id":0,"key":"PlanksBlock","block":"PlanksBlock"}]` 并用 `m:0` 引用；id 使用非负唯一整数，cell 不同时写 `m` 和 `key`；`block` 若填写须与 key 实际映射一致。
- 推荐省略 `size`，由程序计算；若提供 `{ "x":宽,"y":高,"z":长 }`，必须匹配实际方块包围盒，含家具展开后的格子。
- 结构与展开家具合计最多 **10000 格**，任意轴跨度最多 **64 格**；门自动生成的上半格也计入施工限额。每批写入、撤销、回滚最多 **32 格**。
- 剪贴板和文件导入文本最多 **2097152 个 UTF-16 代码单元**（2 Mi 字符预算），此上限不是允许超过 10000 格的授权。
- 不生成 `props`、`state`、`buildOps`、箱内物品、实体、原生家具设计索引、流体、电路、自定义 Mod 方块或能力表之外的类型。
- 不生成空气格；省略的坐标保持原地形。清障只覆盖实际写入位置，不会挖空整个房间或包围盒。

## 家具

`furniturePlacements` 可省略；出现时只能用于 schema 3。可用 `cells:[]` 加家具，但展开后蓝图不能为空。

每项结构：`{"templateId":"WoodChair_A","x":1,"y":1,"z":1,"rotation":0}`。

- 模板 ID 和占地见 [家具表](blueprint-block-reference.md)。10 种模板均展开为已有结构块，并非原版铁锤微体素家具。
- `rotation` 必填整数 0/1/2/3，分别为 0/90/180/270 度；位置是旋转后包围盒最小角。模板默认前向 -Z，依次转向 +X、+Z、-X。
- `mirrorX` 可选布尔值，旋转后沿 X 镜像。`variant` 只支持 `default`，`color` 只支持 `natural`，均可省略。
- 家具完整包围盒（包括内部空隙）不得与结构、门上半格或其他家具重叠。地板应在家具下方一层，不能与家具同格。不能把材料的染色 DATA 当家具颜色字段使用。

## 朝向和依附

几何旋转每步 `(dx,dz)→(-dz,dx)`，会归一化坐标；方块 DATA 朝向由游戏工具同步转换，不能把几何旋转次数直接填入任意方块 DATA。

门只写下半格，空出上半格并计入高度；梯子和火把必须有能力表规定的支撑面。四向旋转会旋转整份蓝图，包括家具。预览箭头表示作者坐标的 -Z 方向，不保证等于建筑主门。

## 游戏内闭环

1. 使用 903 打开蓝图管理，点击“从系统剪贴板导入”。失败保留先前有效蓝图；成功只更新内存。
2. 输入名称并保存，文件写入游戏用户目录下 `BuilderAssistant/blueprints`。重名自动编号，不覆盖；中文名称保存在 JSON 内。
3. 本地列表选择后载入，重启后仍可读取。删除需确认，删除的是所选磁盘 JSON，不删除当前内存蓝图或世界建筑；内存蓝图可重新保存。
4. 点击“选择落点并预览”，对地使用 903。显示包围盒、地面占地、原点、作者前向、Y 范围及最多 128 个占用/不可读格线框；总冲突数和完整校验不截断。
5. 在预览操作条旋转、升高、降低，或再次点地重选。对天空使用、取消、切换工具、离开世界均取消预览。此阶段不写地形。
6. 点击确认后重新核对地形和权限；地形变化更新预览，要求再次确认。清障开启且有占用时需明确确认覆盖数量；取消清障确认返回预览。
7. 使用已有分批施工和 902 撤销。撤销不保证恢复箱内物品、电路、掉落和流体连锁等副作用。

联机普通客户端只读浏览，不可施工。多人需要安装匹配版本，真实同步与 Android 7723 剪贴板、触屏、布局和绘制仍需实测。
