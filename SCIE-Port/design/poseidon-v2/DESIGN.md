# 海神三叉戟·波塞冬 V2：渊海王权设计方案

日期：2026-10-29。基于 main `f746f9e` / SCIE-Port 0.54.0。
本文件是设计提案，尚未修改运行资源、版本或游戏行为。

## 当前实现与判断

代码与资源依据：`docs/POSEIDON.md`、`scripts/New-PoseidonAssets.py`、
`Features/Poseidon/`、`Assets/Blocks/Poseidon.csv`。

现有原创模型为 1 identity 根 / 83 meshes / 1504 triangles，使用不透明色板与普通 BlockMesh。
从生成器输出的正面、3/4 软件图观察，三叉轮廓清楚，但大块金色菱面使叉头像仪仗，
金色宽边削弱了主刃的切削感；弯月支架与长柄的截面变化有限，细金环和小方块装饰重复。
这是离线美术判断，不是设备上的渲染故障结论。

当前已有：原生普通近战基础攻击力 55、水下呼吸、游泳倍率 2.6、潮涌冲锋与沧海怒涛。
冲锋冷却 8 秒，怒涛冷却 26 秒；存在原生权威冲量、服务端命中与包 246。
本轮建议先提升外观和施放反馈，数值平衡另行评估。

## 定位与比例

主题为“执掌深海的王权兵器”：三尖轮廓庄严，刃口危险，水晶带通透层次，长柄能看出承力结构。
与阿比斯的破碎、不对称和紫色虚空形成各自清楚的风格。

建议在当前基础上把可见总长度增加约 10–15%，保持长柄用途；叉头横向跨度增加约 15–20%。
第三人称目标总长约 2.2–2.4 游戏单位，具体以持握和动作预览校准。
叉头占总长约 40%，两侧刃最高点低于中央刃，保持三尖之间的大块负空间。
第一人称先测试当前 CSV，再按视野单独校准，不能直接把第三人称的大尺寸套到屏幕上。

## 几何重设计

| 部位 | 具体方案 | 检查重点 |
|---|---|---|
| 中央主刃 | 长矛形海神刃；厚刃根、隆起中脊、分段收窄的刺尖、两侧独立切削斜面。刃身留一条下沉的潮纹槽。 | 侧面看得到脊背和厚度，尖端真正收尖，减少宽金边。 |
| 左右侧刃 | 海兽獠牙般向外张开、末端稍向内收；内侧加入一处短倒钩，形成抓取和撕裂感。主轮廓左右平衡，纹饰可有细微差别。 | 缩小后仍是三叉戟；倒钩不形成第四、第五根主尖。 |
| 戟架 | 用有折面和分层甲脊的海冠式承力臂替代圆管弯架；连接根部厚，向叉尖逐渐变薄，前后有错开的深度层次。 | 前、后、45°都能读出结构，避免正面好看侧面纸片。 |
| 潮汐之心 | 戟首交汇处放置一颗细长水滴形、多面海青晶体，嵌在有开口的古金框架中。内部深蓝，外侧青白小面。 | 有实体切面和暗部；无大圆靶环，无平面光片替代晶体。 |
| 长柄 | 深海蓝多棱骨架，双握区做深色螺旋包覆；上部两片流线护甲，下部一组鳍形护套。符文以少量实体凹槽/嵌片表现。 | 手柄粗细有变化，握区无尖刺，不再沿全柄重复套金环。 |
| 尾部 | 短而利落的破浪尾锥，带三道鳍脊，与叉头的三分结构呼应。 | 站立和挥动时离地、离腿的距离；物品图标中的完整轮廓。 |

不为每个部件建立骨骼。候选仍使用 Y_UP、meter=1、单 identity 根、烘焙变换和独立 geometry。
建议预算为 4,000–6,000 三角形、约 20–30 组几何，超预算需说明视觉收益。
旧模型已合并到一个 BlockMesh 绘制，减少 geometry 数量不能宣传为同比减少运行时 draw call。

## 材质与配色

| 区域 | 建议色 | 视觉面积目标 |
|---|---|---|
| 主体金属 | 深海蓝 `#10364C`，暗部 `#071B30` | 约 55% |
| 晶体、刃槽与局部海青面 | 海青 `#238CA8`、水晶青 `#66D4DF` | 约 25% |
| 连接件、王冠纹饰 | 古金 `#B58B43`，亮面 `#D9BE7A` | 约 15% |
| 薄刃口与晶体亮面 | 珍珠白 `#D5EEF1` | 约 5% |

以上比例是美术目标，需实际渲染调整。深蓝金属使用几何斜面与多级明暗，晶体用独立切面和内外颜色
表现层次。目标原生物品材质没有已接入的 PBR/折射方案，因此不承诺真实折射、镜面反射或玻璃效果。
可选自发光仅限少量符文和晶体内芯，主体在无粒子、无自发光状态下也必须成立。

## 技能与触屏呈现

第一轮保持既有技能功能和数值，将以下内容作为后续独立演出阶段：

1. **潮涌冲锋**：三叉戟短促前送，叉尖形成收束水流；侧后方留下两股弯曲尾流，
   命中时出现短水压爆点。结束时收势明确，不让长水带遮住准星。
2. **沧海怒涛**：沿用现有 0.3 秒聚潮窗口，用戟尖汇水、低位水纹和低频海浪声表达蓄势；
   前进阶段突出深蓝浪腹、卷曲浪冠、稀疏白沫，减少完整发光线条造成的“能量墙”印象。
3. **常驻呈现**：能量主要集中在武器上，持有水滴进一步节制，避免持续包围玩家。
4. **技能徽记**：深海蓝底、古金细边、海青单色主图。两枚保持已有操作习惯，增加清楚的冷却扇区；
   若改为圆形控件，视觉与实际触控命中区一致，继续避让原生按钮、快捷栏并支持左右手布局。

手持动作需先核对目标第一/第三人称 API，以及 Poseidon 现有主机/客户端演出时序。
视觉故障不影响命中计算，材质或水滴关闭后技能仍执行现有权威判定。
新连击、投掷召回、召唤海兽、海域地形与天气不属于这份外观优化的默认实施范围。

## 交付与实施顺序

1. **独立候选**：新建候选 DAE/PNG 与可重复生成脚本，先出无色灰模和六视图，不覆盖正式资产。
   六视图为图标、完整正面、45°、三维透视、第一人称、第三人称；补背面与晶体/刃口细节。
   额外检查 32/48/64 像素图标、实际持握比例、低光与无特效画面。
2. **确认后接入模型**：保留 Block ID 951、DATA 0、原 XDB GUID 和包 246，调整美术与必要的持握参数。
   原生模型导入、拓扑/法线/UV/PNG、Test-Environment、Release、包资源检查通过后交付 `.netmod`。
3. **施放演出与 HUD**：单独改进动作、水浪、声音和冷却提示，保留现有命中/权限，重新做联机与触屏检查。
4. **用户 Android 验收**：用户亲自在客户端测试，分开记录单人、房主、普通客户端、第一/第三人称、
   水中、低光、左右手触屏及性能。离线预览与 Windows 构建不作为 Android 实机通过的证据。

后续预计涉及：`scripts/New-PoseidonAssets.py`、模型/纹理、`PoseidonBlock.cs`、`Poseidon.csv`；
演出阶段涉及 `PoseidonScene.cs`、`PoseidonHud.cs` 和必要的动作呈现适配；验证脚本、来源/哈希、
兼容文档与测试记录随实际变更更新。

## 海神V2技能和配色（0.55.0）

用户最新规格已进入实现：水御潮环15秒（领域7秒）、14伤害与刷新5点盾；沧海怒涛11秒（领域5秒）、44伤害；海神领域60秒、持续20秒、55伤害与刷新5点盾。伤害与有效护盾水中翻倍，水中行动速度+200%（3倍）。本轮只调整原模型配色，完整几何重构仍是后续候选阶段。图标使用image_gen生图，三个技能围绕查看排布。具体语义、来源、测试和设备验收见../../docs/POSEIDON.md。
