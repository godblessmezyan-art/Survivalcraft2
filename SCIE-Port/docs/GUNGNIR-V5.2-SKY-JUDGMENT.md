# 昆古尼尔 V5.2：神王敕令·天穹审判

版本：SCIE-Port 0.35.0。日期：2026-10-27。目标：SCNET `Net_x25.01.17`。

本记录中的“已确认”只代表固定 Windows 目标程序集取证、源码审查、纯规则测试、Release 构建和包结构验证。没有进行 Android 7723、游戏内画面或双机联机实测。

## 实现边界

- `GungnirSkyVisuals` 按 `Project + caster entity id` 管理 9 秒视觉状态，只读取 `SubsystemTime` 和玩家本地身份，不写 `SubsystemWeather`、昼夜、降雨、地形或生物属性。
- 包 244 的字段、序列化顺序和长度未改变。客户端继续用既有 `Sequence` 排除重复/乱序快照，以 `JudgmentAge` 恢复时间轴；同一施法者只有一个天空状态，后续快照只刷新目标和存活时间，不重复创建状态。
- 只有 `PlayerData.IsMainPlayer` 的施法者改变本机天空。其他玩家仍通过既有权威快照看到目标处的巨枪、法阵、光带、符文和冲击波。
- `ChangeSkyColor` / `ViewFogColor` 没有 Camera 或 Project 参数。实现沿用已验证的雷暴方案：只汇总本地主玩家状态，项目 Dispose 时显式清理。该 ABI 无法为同一进程的多主视角/分屏提供逐相机天空，属于待验证限制。
- 没有直接改原版云模型。暗青云层汇聚用目标上空的有界远景色带代替，避免依赖未验证的云层内部 API；真正的天幕暗青/暗金渐变由天空 Hook 完成。

## 四阶段时间轴

1. **神王敕令，0–1.2 s**：天空平滑转为暗青黑/暗金灰；地阵从中心向外点亮；天空法环差速旋转；真实 Gungnir 网格在 25 格高处由 1.15× 凝聚至 3.55×；远景光带汇入枪身。神枪不提前落地。
2. **天罚降临，1.2–1.4 s**：在 0.2 秒内完成 25 格至落点的三次方下坠，叠加白金枪体、模型能量脊、模型符文和分层金色尾迹；仍与原权威 `1.4 s` 伤害时点一致。
3. **永恒裁决，1.4–3 s**：尊重减少闪光设置的白金主闪、三道大型冲击环、中心向外的地阵、破碎扩散的天空环、中高画质远近光柱；所有内容仅进入绘制批次。
4. **神谕余辉，3–9 s**：暗青/古金天空保持后于 7 秒开始平滑恢复；漂浮符文和能量碎片逐渐衰减；动态色带向外散开；9 秒时删除状态。

## 与妙尔尼尔天空并存

- 雷暴独立状态、闪光和清理逻辑未改。
- 两者同时存在时，整体强度使用 `1-(1-storm)(1-divine)`，色相按各自强度加权；相等强度下神王天幕权重略高，但雷暴仍保留。神王天幕结束后权重精确回到纯雷暴路径，两者结束后回到原版天空/雾色。
- 水下和岩浆雾完全不处理。雷暴蓝白闪光与裁决金白闪光独立合成，两者都尊重 `ReducedFlashes`。

|---|---:|---:|---:|---:|---|

## HUD 与投枪修复

- 昆古尼尔 HUD 删除额外的矩形 `Frame`；透明图集中的圆形金属徽记、冷却数字、按压增亮、呼吸光和能量条保留，触摸区域仍等于图标本体。
- 偶发投枪失败的风险来自 `OnAim` 返回未处理以及普通客户端完成长按时没有明确向权威端发送投枪生命周期。现在 `OnAim` 返回 `true`，并在包 244 现有 `Phase` 字段上传递开始/完成/取消，在现有 `Blessing` 浮点槽上传递完成时的本地长按时长；没有增加字段或改变序列化。
- 服务端必须先收到开始信号，并用服务端计时验证 0.25 秒；只有开始/完成包被同批送达时才使用有界的客户端时长补偿。重复、乱序、无开始、短按及超过 10 秒的报告均拒绝。速度 35、距离 40、最多 8 目标、回程 45 和伤害完全未改。
