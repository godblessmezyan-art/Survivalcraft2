# 冥界军势随机召唤 / 0.72.0

2026-11-02，基于 main `84f13d6` / 0.71.0。移除指定类型召唤，保留「召唤」按钮。只提交本地 main，不推送。

## 规则

手持终焉之镰 → 死亡权柄 → 冥界军势 →「召唤」。不再显示类型切换、概率表或常驻机制说明。面板从540×632缩为540×586，七行契约及管理操作整体上移46逻辑单位，沿用按可用尺寸统一缩放、Identity变换和边界裁剪。

每次有效尝试由单人运行端或房主在主线程调用一次 `System.Random.Next(100)`，均匀抽取0～99整数：

| 结果 | 权重 | 抽签区间（含端点） |
|---|---:|---|
| 地狱三头犬·刻尔柏洛斯 | 5% | 0～4 |
| 骨龙 | 10% | 5～14 |
| 夜魇骑士 | 15% | 15～29 |
| 夜魇战马 | 20% | 30～49 |
| 冥界猎犬 | 30% | 50～79 |
| 召唤失败 | 20% | 80～99 |

抽到失败时不创建实体、不占名额，只反馈「召唤失败」。每次有效尝试在抽签前进入**60秒冷却**，成功、20%失败、重复唯一生物、无安全落点或实体创建异常均消耗此次冷却；不会重抽、改权重或退回冷却。重复唯一生物/空间不足保留简短原因反馈。因此已拥有唯一生物或环境不适合时，实际总失败率会高于20%。

无效角色/持物状态、未切换死亡权柄、未到冷却、鉴权/世界/序列失败、请求限流，以及每人7只或世界24只名额已满，均在抽签前拒绝，不抽取也不新增冷却。次位面与待加载契约仍占名额，并计入三头犬/骨龙每位主人各一只的唯一限制。骑士、战马、猎犬可重复。

冷却继续使用运行中世界的GameTime，与原机制一致；本次不新增跨世界退出的冷却持久化。收回、召出、夺魂转化、战斗参数、模式、骑乘、治疗和原有契约身份保持。

## 网络与兼容

252包ID及字节布局保持，无新Hook或加载器ABI。Kind0/Action4是随机召唤请求，**主机忽略Target**；新的面板请求默认Target=0，伪造旧类型编号或其它值均不能选择结果。随机生成和创建实体只在Local/Server的队列处理阶段发生，客户端只接收结果与冷却。

Kind1的D继续表示剩余召唤冷却，上限校验由30.1扩为60.1秒，并沿用包年龄扣除、世界/连接Token/主人/实体/修订检查，旧包不能清除新冷却。Kind3的D仍是行动模式，与Kind1的冷却字段相互独立。

同房各方统一0.72.0；旧版会拒绝超过30秒的状态，且仍显示类型选择，混装 **不支持**。契约仍读v1/v2、写v2，既有生物及次位面无需重建。无新模型、贴图、模板、方块/物品/生成蛋ID、地形操作或Builder Assistant蓝图材料变化。
