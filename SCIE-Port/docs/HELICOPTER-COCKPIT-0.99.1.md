# 直升机座舱 0.99.1

原生 `FppCamera.Update` 跟随人物的 `EyePosition`。直升机的双座挂点在机身局部 Y=1.05，骑手再应用自身偏移。原生人物眼位继续叠加接近站姿的高度，导致坐进直升机后相机仍位于舱顶上方。旧模型同时把前风挡、侧板和高鼻罩并进了不透明机身，直接压低相机也会被挡住。

- 驾驶位与副驾位分别使用距机身基准高度 1.33 格的眼位，朝机鼻前方。相机使用当前实体位置、朝向及模型 `VisualRoot` 的俯仰与侧倾，触屏观察沿用人物的原生视线输入。
- 舱内第一人称显示前窗、侧窗开口和窗框。第三人称、旁观者和物品栏显示深色玻璃。玻璃单独占用一个骨骼，实体共 7 骨骼、6 网格、1,110 三角形。
- 两个座位前的倾斜仪表台各有三枚指针，从左至右显示水平速度、垂直速度和旋翼转速。垂直速度表以中位为零。逐帧从飞行组件读数，原有飞行 HUD 继续提供数字读数和总距控制。
- 原生相机实例负责视角切换。离座、死亡、座位动画和 VR 路径使用原生视角。新版模型通过 941 的现有实体模板加载，座位职责由现有双座组件管理。

固定 Windows x25.01.17 组件测试覆盖座位绑定、相机方向与倾斜、舱内与外部玻璃切换、离座和三组仪表值。Engine/OpenGL 合成图展示驾驶位、副驾和外观。

Android 7723 实测项目包括横屏触摸观察、起飞转向后透过风挡辨认地平线、低头看表、前往副驾、切换第三人称、下机和旧世界重载。真实联机需由房主与普通客户端分别进入左右座，并观察旁观者所见外观。第三人称人物目前使用 SCNET 通用骑乘姿势。
