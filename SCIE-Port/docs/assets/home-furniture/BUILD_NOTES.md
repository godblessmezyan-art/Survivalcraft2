# Home authoring handoff

The selected backend is the official Blender MCP, source commit `dbbf836ad4b1025f14a2b3b504c43903f39e0b04`, package 1.0.2, on Blender 5.1.1. Codex's `blender` stdio entry starts an isolated background instance on 127.0.0.1:9877. The original Codex configuration was backed up locally before adding this server. Installers, tool checkout, virtual environment and backup remain outside this repository/package.

Skill order: `text-to-blender` and `blender-skill-harmonizer` select this backend and the project ABI; `blender-pro-workflow` sequences geometry, UV, material and preview gates; `blender-modeling`, `blender-materials`, `blender-uv-texturing`, `closed-surface-uv-coverage`, `blender-cameras`, `blender-lighting`, `blender-rendering` produce and inspect the artifacts. The project's verified DAE/PNG contract takes precedence over generic GLB/PBR export recipes.

Actual MCP requests listed tools, inspected the fresh default scene, ran the authoring module, built all `NAMES`, rendered 16 front views and six rear views, and saved the editable `.blend`. Requests were serialized; no concurrent scene mutations. A dedicated long-lived background process holds Blender state between short stdio clients. Each code request reloads functions and looks up scene objects by stable names rather than depending on Python variables from previous requests.

To reproduce, import `scripts/New-HomeFurnitureAssets.py` inside Blender through `execute_blender_code`; call `setup()` once in a new scene, `build(name)` for each `NAMES` entry in order, `render(name)` / `render(name,'back')`, then `save()`. Keep requests small. The serializer bakes geometry and normals into `(x,z,-y)`, emits one identity node, and assigns independent POSITION/NORMAL/TEXCOORD offsets. Scene materials/lighting are for Blender previews; runtime receives the opaque color atlas and native SCNET shading.

Outputs: source game assets in `src/SCIEPort/Assets`, manifests here, editable packed-texture gallery at `artifacts/home-furniture/CozyFurniture.blend`, individual proof renders and MCP transcripts under `artifacts/home-furniture`, and a six-family contact sheet here. `Prepare-HomePreviews.py` arranges real renders without retouching them. The saved `.blend` was independently reopened: 16 named collections, packed texture, gallery mesh X positions approximately -3.605 to 3.685. The optional official MCP CLI-query helper timed out once; the same file read directly with Blender's factory-startup/disabled-autoexec flags exited successfully. Core connected-scene modeling/rendering/save calls succeeded; broad optional CLI helper coverage is not claimed.

Static UV/triangle/index/PNG checks complement actual target `Engine.Media.ModelData.Load`. The final set has 16 models, 30000 total triangles, one imported bone each. Tests caught default UVMap use, clamped-bevel degeneration, a wall-cabinet plinth and a corner seam; corrected exports were reimported and rerendered. No source image was supplied, so registration is a coordinate/export contract rather than an invented image-fit score; overlay images are not applicable.

Actual native protocol registration uses 239. Registry length is 255 (valid 0–254), so 255 is invalid. Native package streams compress data; the fixed 17-byte assertion applies before compression, with a real compressed/decompressed roundtrip for both actions. Runtime world/device/GUI/multiplayer acceptance remains pending as documented in `HOME-FURNITURE.md` and `TEST-RESULTS.md`.
