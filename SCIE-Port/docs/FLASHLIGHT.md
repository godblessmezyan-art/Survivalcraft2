# 手电筒（1.11.0）

手持手电筒后用原生互动操作开关。「装备与工具」提供一支满电且关闭的手电筒，已有快捷栏换槽和丢弃操作可以收起它。重新选中时，手电筒按物品保存的开关状态恢复工作。

## 合成和电量

| 原版灯泡 | 铁锭 |
| --- | --- |
| 原版电池 | 铁锭 |

满电连续照明约 300 秒。开启且选为当前手持物时，每累计一秒游戏更新时间消耗一格电量。关闭或收起时暂停，物品栏电量条归零时自动熄灭。将有耗电的手电筒和一枚原版电池并排放入合成格，可得到一支满电且关闭的手电筒。

## 照明和联机

- 约 15 格的暖白光束以当前玩家游戏相机为光源，随视线移动，边缘和远处逐渐衰减。目标地形批次保留纹理、雾、透明度和深度遮挡。照明显示在持有者的画面中，村落或洞穴的地形光照数值照常运行。
- 单人直接操作槽位。普通客户端发出开关请求，房主验证发起连接和当前手持槽，执行开关与扣电，然后经原生库存包同步结果。请求 231 仅携带快捷槽编号和目标开关状态，共 2 字节。
- 物品索引 890。DATA 位 0 为开关，位 1 及以上保存已消耗的整数秒。值 0 为满电关闭，值 600 为耗尽关闭。耐久条用来显示电量，普通挖掘与攻击不改变电量。手电筒不可放置、不可堆叠，无蓝图材料或族标签。
- 灯头和筒身使用原创低多边形网格。照明使用运行时读取的目标地形着色器，增加距离和角度衰减。相机绘制完成后恢复原生着色器。着色器布局不匹配或编译失败时，恢复原生绘制并记日志。

## 实机验收

首次测试使用可丢弃的新世界。Android 7723 **待验证**，需检查夜间和洞穴中的开关、换槽停电、普通及宽屏触摸、视角切换和原生着色器加载。真实联机 **待验证**，需检查房主与普通客户端分别开灯、快速换槽、用完电池、保存重进和掉线后电量同步。联机各端统一版本。
