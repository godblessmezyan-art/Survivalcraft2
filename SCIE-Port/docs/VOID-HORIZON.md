## 原生深度方案与限制

已反编译固定x25.01.17及Engine程序集核对，原生代码只保存在忽略的artifacts取证目录，不提交：

| 管线 | 已核对行为 |
|---|---|
| SubsystemDrawing / ViewWidget | 每相机按DrawOrders排序绘制；低/中分辨率用Depth24Stencil8缩放目标，之后才复制到UI。领域在目标仍绑定时绘制。 |
| Sky -100/5/105 | 天空准备、天空与闪电；不会在本领域末尾前清除世界深度。 |
| Terrain 0/100 | 不透明/AlphaTest地形以及透明水体均使用DepthStencilState.Default，写入可用深度。 |
| Models 1/99/201 | 不透明、透明模型按原生方式写深度。第一人称物品在1号层用压缩深度区间，不清除世界深度。 |
| Particles 300 / ScreenOverlays 1101 | 在领域前绘制；不假定所有粒子或第三方绘制都会写深度。 |
| 相机 | 原生透视near=0.1、far=2048，效果复用同一投影；无固定屏幕坐标圆形遮罩。 |
| RenderTarget2D | 深度是GL renderbuffer，未暴露可采样深度纹理；不能虚构深度采样Shader。 |

末尾DrawOrder=2147483631保持。侵蚀是以当前视点为中心的360°三维收缩球面：原生LessEqual只让球面遮盖其后方的场景像素，近处山体/水/模型的真实深度挡住球面。球面在世界轴方向上使用固定低幅噪声，连续单调收缩；镜头转动不改变侵蚀距离。不是把整张屏幕统一调暗。球面中心随观察位置，黑洞的世界位置独立固定。

主面之前画三个稍靠近观察者的半透明深度球面，再由主面覆盖远侧辉光，于是只在真实景物与移动边界相交的窄带保留紫光。所有层禁止写深度，不清除、不读取回CPU、不复制或改写原生深度缓冲。黑洞侵蚀阶段按同方向投影到球面附近参与相同深度测试，避免已经消失的山峰继续挡住黑洞；网格细分导致边界附近存在小幅深度近似误差。3.1秒后完整背景才可使用DepthStencilState.None，4.2秒全部结束。

前沿越过原生0.1近裁剪面时，只将相机前方过近的顶点沿各自观察射线移至0.1005深度，投影位置保持不变，避免球面被近裁剪切掉而在边缘重新露出世界。不是全屏遮罩；原世界有效像素本就位于近裁剪面之后。GPU额外检查3.08/3.09/3.099秒三档及旋转/仰俯交接均不露回已侵蚀景物。

运行颜色是straight RGBA，使用已核实的BlendState.NonPremultiplied，避免原生AlphaBlend的预乘约定造成亮晕过曝。复用黑洞暗核、前后吸积盘及弯曲盘面透镜；没有实际屏幕像素折射/高级引力透镜Shader。空间扭曲由几何形变与碎片表达。球面替换是兼容当前原生接口的方案，不声称已实现深度纹理后处理。

原生不写深度的粒子、无深度的第三方物体和后于此层绘制的其它Mod，不能保证按它们自身距离切分；水下叠色、特殊透明层及第三人称偏移需实机观察。普通地形、原生水体和正常模型的距离遮蔽已经过Windows原生GPU合成场景验证，不能替代Android游戏实拍。

## 湮灭结算

旧版只打180名义攻击力、默认跳过被动动物、每轮最多24目标且最多扫512物体；不足以保证高抗性目标死亡。新版取消侵蚀跳伤、牵引和固定攻击力终击，覆盖时一次性提交结算。

- 以施法起点为中心，水平半径128格、高差不超过256格，查询该范围已加载的原生生物；普通动物、捕食者和高血量生物都可受击，不再依赖AllowPassive。没有旧24目标/512扫描截断。
- 没有墙体视线要求；仍拒绝未加载目标区块与原生领地保护区中的目标，施法起点也须在非保护区。没有新建区块、清理全世界存档或改地形。
- 所有ComponentPlayer无条件排除，和友伤开关、AllowPlayers、分类标签无关；载有玩家的直接坐骑/承载体也排除。实际伤害入口再次拒绝玩家。
- 使用原生ComponentHealth.Injure，按当前标准化生命值给足致死量，ignoreInvulnerability=true，绕过普通护甲/抗性缩放及普通无敌标志。原生第三方OnCreatureInjure仍可否决伤害，特殊非原生生命系统不在此接口保证内。
- 使用环境型“阿比斯·虚夜湮灭”伤害，正常死亡、掉落和健康状态包由原生处理，不为每个目标额外触发攻击者经验球循环。
- 每次施法只提交一次范围快照，去重后每个实体至多一次。共享每帧128项检查预算，常见数量在覆盖帧结算，大量实体在紧接的数帧完成；领域不因此延长。600 NPC夹具覆盖了超出旧目标限制的批量结算。大型密集场景的实际帧率和网络吞吐需真机验证。

## 免伤、网络和生命周期

从主机接受施法开始，到4.2秒边界前拦截原生伤害、护甲损耗、攻击击退与眩晕，保留转向并锁定主动移动/攻击。既有物理重力仍运行，不传送施法者。冷却仍为180秒，持有移速+20%、近战频率+10%及专属背景保持。

249号包字段和身份/序号/修订号/取消标记不变，250星门协议不变，v1星门存档不变；为看到相同演出，主机与客户端均建议升级0.60.0。普通客户端只能请求技能和播放主机快照，不能提交致死量、目标或可信位置，不能自行造成伤害。状态快照0.5秒间隔、2秒无响应取消的保护保持。

覆盖前取消不产生湮灭；覆盖后已经提交的有界结算继续处理，但施法者移除/身份变化或世界Dispose会清理。领域离场时立即撤销免伤；不靠补血、直接删除实体或永久修改IsInvulnerable实现效果。
