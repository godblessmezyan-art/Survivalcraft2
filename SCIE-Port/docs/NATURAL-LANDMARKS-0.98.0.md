# 自然地形 0.98.0

五类地标在荒野探险家现有生态之后生成。支持 `Continent`、`Island` 和 `Better` 世界的原生新区块。旧世界可向未生成的区域探索。地形使用现有方块与水流，通过原生区块系统保存和同步。

| 地形 | 选址 | 生成内容 |
| --- | --- | --- |
| 瀑布与跌水潭 | 暖湿内陆断崖，崖顶能容纳泉槽，崖脚有低洼地或同水位河潭 | 原版水从两格泉槽流入 4–14 格落差的垂直水柱，落进两至三格深的跌水潭。岩壁厚度合适时，水幕后可能有一间可游入的岩洞。 |
| 浅滩渡口 | 两岸都能站立，水面连续 3–8 格，踏石位置的水深不超过四格 | 露出水面的踏石间隔一格，两端用碎石标出落脚处。部分渡口旁有一小段断木桥。 |
| 樱花溪谷 | 温润内陆，有连续水面、两侧溪岸和适合樱花树生长的土壤 | 沿岸生成两至三棵已有品种的粉色樱花。靠溪有合适的平地时出现一块两格见方的岩石平台。 |
| 海蚀拱门 | 海岸接近水平，陆侧有可承托的岸体，外侧岩脚可以落到海床 | 不规则石拱连接岸边和海底岩柱，中央保留至少三格宽、三格高、两水格深的通道。 |
| 雪线岩棚 | 海平面以上至少 14 格，气温到达原版结冰线，近旁有可走的冷区岩壁 | 切出五格宽、最多三格深的岩棚，净高两至三格，保留天然岩顶和岩底，可放篝火。 |

每种地形使用种子驱动的选址。瀑布、渡口、樱花溪谷、石拱和岩棚的每区块尝试概率分别为 14%、19%、23%、23% 和 24%。每区块最多落地一个本版地标。实际遇到的频率由地形、水深、植被和同区块空间共同决定。生成尺寸和候选数有上限，所有主体落在区块内侧 1–14 格，只检查该区块内容。计划确认后才写入，瀑布和水下地形完成后补算受影响水体的原版液面标志。

安装包已按目标 `Net_x25.01.17` 编译。依照本次沿用的验证安排，游戏内观感、种子下的分布密度、船只通行和原生水流演化由用户实测。
