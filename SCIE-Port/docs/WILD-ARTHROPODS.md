# 沙蝎和招潮蟹

两种生物接入普通地表的原生刷怪入口。沙蝎出没于暖干的沙地和砂岩地表。白天伏低，夜间在附近巡游。受惊时先扬沙并抬尾，约 0.72 秒后向蓄势时锁定的方向扑刺。玩家可侧移、退开或绕到掩体后。命中复用原生护甲和伤害结算。

招潮蟹出没于有一格深浅水的沙岸、砾石岸和泥岸。遇到玩家时横向退入浅水，等威胁离开后返回活动点。击败会掉落一份招潮蟹饵。把它放在鱼竿右侧一格即可挂饵，沿用现有钓鱼计时、消耗和大鱼判定。原有黑麦和野黑麦也可用作鱼饵。

## 测试入口

「自然与生物」有沙蝎生成器和招潮蟹生成器，用于单机或房主的手动放置。点有净空的地面顶面可释放。自然刷新适用于原生地表刷新可到达的已加载区域。两种生物每次各刷一只，同种在生成点周围 14 格内达到 2 只时暂停该点刷新。回到旧存档时，新生物沿用野外实体生成流程。

Windows 固定目标 Net_x25.01.17 已通过原生模型导入、数据库继承、地表与浅水筛选、侧移避刺、鱼饵兼容和网络编号检查。Android 7723 上的触屏命中、刷新密度、上岸动作与真实联机待实测。
