# 冥界军势行动模式 / 0.70.0

2026-11-02，基于本地 main `903afcd` / 0.69.0。只提交本地，不推送。适用于已召唤、转化及已有契约生物，无新物品、模型、生成蛋或方块 ID。

## 使用

手持终焉之镰 → 死亡权柄 → 冥界军势 → 选中一只 → 点按列表下方的「模式」按钮（0.70.1起文案精简）。每点一次循环 **护卫 → 自由行动 → 攻击 → 护卫**。设置按契约独立保存，次位面和待加载的契约也可预先设置，现身后生效。新召唤及缺少模式字段的旧档默认护卫。

| 模式 | 实现行为 |
|---|---|
| 护卫 | 保留跟随主人、攻击敌对生物及护主目标，不主动攻击普通中立生物。 |
| 自由行动 | 停止跟随及自动归队，在切换或重新加载时的位置附近漫游；不自动攻击，也不响应护主威胁。关闭该只生物的骑乘自动追击，骑乘仍可手动控制；如要重新开启追击，先切换护卫或攻击。 |
| 攻击 | 主动选择包含中立生物在内的非玩家生物；沿用跟随与追击范围。所有玩家、全部契约友军、承载玩家的坐骑/身体以及原有领地保护继续排除。 |

自由行动不提供无敌，仍会受伤；手动「召回友军」仅在距离主人超过48格时尝试归队，归队后重置漫游锚点；近距离可用单只/批量收纳、现身调整位置。自动攻击和伤害仅由单人/房主裁定，普通客户端不能直接提交伤害。

## 高处避让修复及漫游边界

旧让路目标由「玩家位置 + 向外方向 × 距离」生成，仅验证列已加载和非领地，没有检查地面支撑。0.70.0 取消该强制外移目标：未骑乘召唤物在玩家附近停步，每帧清除水平速度和本功能路径，保留竖直速度及原生物理。触发水平距离为 `1.7 + max(BoxSize.X, BoxSize.Z) / 2` 格。保留原有临时碰撞质量软化与恢复，骑乘时继续由骑手控制，不强制刹停。

自由行动单次目标约2.5格，每3～4秒尝试一个方向，目标及实际漫游位置限制在本地锚点6格内。只接受同高、全部身体占地有完整稳定支撑、身体净空为空气的短路线；每0.5格采样，最长4格。必须已加载、非保护领地，拒绝流体/带碰撞行为的地板、墙、缺口和高度变化；坡阶、窄山脊或区块未加载时可能停留。每次思考复核当前路线，失败即停步；不启用绕障寻路，避免经未经检查的绕行路径跨出支撑区域。每路线最多1024次格检查，全部军势共享每帧4096次预算，耗尽即停步，处理顺序沿用轮转。

以上修复的是本功能发出的避让/漫游命令。原生物理碰撞、外力推挤及战斗寻路仍须在真实山地场景验收，没有增加跌落免伤或修改地形。
