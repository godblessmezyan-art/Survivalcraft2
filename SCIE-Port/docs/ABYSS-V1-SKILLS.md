# 阿比斯 V1 开发预览 0.52.0（未完成）

当前已整合到 main，基于 `codex/abyss-v1` 预览并保留主线紫曜巨镰 A3 和四圣兽。所有游戏内行为为待验证；不能将该预览描述为 V1.0 或 Android 兼容成品。

| 项目 | 状态 | 实现和仍缺内容 |
| --- | --- | --- |
| 一：裂界星门 | 待验证 | 本地/本地主机触屏建门、观察门后交互、命名、设置目标、取消与删除；权威记录经世界子系统保存；远处目的地申请临时区块加载，周边全部就绪后再检查落点，等待 10 秒后取消；目标程序集隔离测试通过，真实加载待验证。预览只允许创建者管理，拒绝原生领地及边界。普通客户端的记录同步和操作不支持。真实退出重进、图形、物理和触屏未验证。 |
| 二：断界斩 | 待验证 | 保留原 V1 的 25 格、6 格宽、10 秒、100/40 攻击力及包 247；状态、输入、原生墙体与领地夹具回归通过。音效和 V1 演出优化尚未完成；Android/联机仍待验证。 |
| 三：虚影瞬狩 | 待验证 | 单人及本地主机尝试 18 格内地面落点或目标侧后方，15 秒冷却，猎杀落地后最多 24 个目标各一次 70 名义攻击力；检查已加载区块、落点、原生领地、实体/移动方块、墙体和攻击许可。只有短裂隙线条预览，动作、残影、屏幕反馈和设备体验未完成。普通客户端不支持。 |
| 四：终焉坍缩 | 待验证 | 单人及本地主机代码使用 17 秒、180 秒冷却，40 格水平范围和 12 格高度，8–14 秒脉冲侵蚀、牵引及 16 秒一次终结；每次扫描最多 512 物体、64 次射线和 24 个结算。原生天空色 Hook 和独立绘制类呈现分叉裂隙、黑心、多层旋转环、地面符纹与终结冲击环；低/中/高等级使用固定循环上限，黑心在 15.7 秒前收缩，最终爆发从 16 秒开始；仍为简易预览，增加四段原创音效和跳帧过期保护，声音播放失败不影响战斗；距离目标演出和完整反馈仍有差距，游戏内实际音效待验证，不能宣称视觉验收。普通客户端请求、状态与特效同步不支持。 |
| 触屏和视觉 | 待验证 | 四槽分别接受逐指点击并显示冷却，第一、三、四槽为新代码；布局复用旧防遮挡逻辑。`PortalEffectQuality`、`BlinkEffectQuality`、`HorizonEffectQuality` 为 0/1/2，分别控制简易场景预算；断界斩仍使用原 `WorldCutLowEffects`。图标仍为文字，移动端多指、左右手与分辨率尚未测试。 |

原生 `ComponentBody.Update` 在 Server 上会用远程玩家的 `netPosition` 更新其位置；虽存在 `ComponentPlayerPackage.PositionSet`，仍需解决在途 BodyUpdate 的过期覆盖、确认与重放保护，不能将直接写位置视为权威同步。`TerrainUpdater.RemoveUpdateLocation` 不会清掉排队中的添加。0.50.0 在已审计的 Windows API 上同时核验私有排队表和已应用位置，取消时安排排队删除并避免覆盖其他写入；真实工作线程与 Android 7723 尚待验证，私有字段不匹配时主动加载拒绝、已加载的目标仍可尝试。

配置 `VoidPortalLimit` 默认 12、限制在 1–64；下调低于现有记录数时保留原上限，避免删除记录。传送落点只接受已加载、完整安全地面和空气空间，拒绝碰撞、流体、危险方块和原生领地；不写地形。第三方领地保护需另行适配。

操作失败、技能中断、换世界和冷却边界还需真实游戏覆盖；在新建可丢弃世界测试，勿使用主存档。用户已取消自动关机要求。
