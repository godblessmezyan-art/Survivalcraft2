# 神器技能排列规范 · 0.57.0

所有已实现的触屏战斗技能入口统一走 Artifacts.ArtifactSkillHud / ArtifactSkillLayout：昆古尼尔2技能、波塞冬3技能、阿比斯4技能、觉醒雷神之锤2技能和四圣兽单入口。全知之眼的扫描结果面板、吞噬之眼的交互对话框属于工具操作，不虚构新战斗技能按钮。

默认右手布局：技能区位于原生查看左侧，技能1在下方，后续普通技能沿向左上弧线排列，最后一槽为上方大招。普通按钮72逻辑单位，大招88；单独四圣兽入口保持76。左手模式镜像到查看右侧，保证远离左侧移动区。以真实LookWidget为锚点，不写死屏幕像素。

每帧统一收集原生按钮、点击区、移动摇杆、快捷栏和其他可见技能入口；保持4单位安全间距。限定6次向内、18次向上搜索，无法容纳则隐藏整组按钮。圆形图片只接受圆内点击；根面板及装饰不抢世界触控。技能实际身份、序号、冷却、权威请求与联机包保持。技能区只随持有武器切换。
