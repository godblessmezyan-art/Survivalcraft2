# 物品尺寸与植物生态 0.93.0

## 尺寸

核查了移植工程内 80 条方块与物品 CSV 条目及其对应绘制路径。普通方块沿用一格大小，载具继续使用各自的物品预览和实体模型，神器与工具按原有握持点绘制。农业产物使用同一网格绘制背包、手持和掉落，第一及第三人称取原生掉落倍率 0.3。物品栏放大预览，并按网格实际中心对齐。

苹果网格宽约 0.44，手持、掉落和旧存档中曾放置的苹果显示约 0.13 格宽，约为现在莓果束宽度的 1.7 倍以上。枝上成熟苹果也约 0.13 格宽。玉米棒比苹果长，玉米种子、向日葵籽、大豆和亚麻纤维改用立体物品网格。苹果仍可食用，苹果树苗、树干、树叶继续使用原 939 的独立 DATA 角色。

## 生长与收获

原生方块扫描驱动植物生长。主机和单机推进状态，并用原生采收和地形更新同步。年生作物读取原版耕地的水分和氮肥。野生作物用 DATA bit 3 标记，允许在自然表土成熟。玩家补种使用普通种子，按现有配方和施肥机制种在耕地中。冷、旱、弱光会暂停生长，将世界的环境行为设为静止也会暂停。年生作物成熟后收割并用种子补种。

- 苹果树苗有七次生长和成树检查。在有空间的地面成熟为 21 格树体。四个下层枝位春季开花，夏季长青果，秋季每枝至多收两颗。秋季采完后保留空枝，进入下一生长季恢复。关闭季节变化时，在合适气候中持续循环。树冠缺失时可在春季恢复，固定季节的世界按轮询恢复，完整树干和空位是前提。
- 野莓春夏结果，耐冷云莓主要在夏季结果。种下果实可获得相应的幼株，成熟时每次收一份。云莓再生慢于野莓。旧成熟莓果数据照常读取。
- 竹在温湿地带长得较快，保留根部后继续生长，最多八节。香蒲需要水边有土或沙，采嫩茎后经历三个恢复阶段。
- 仙人掌果只能种在原版仙人掌顶端，采后经过芽、花、青果重新成熟。橡实种植直接使用原版橡树树苗及其生命周期。
- 常驻菌丛与玩家播种的菌丛在湿润、有遮阴的土上逐步成熟，收获 1 至 2 个菇后再生。旧临时菌丛仍保留原干燥时限。毒蝇伞生成更稀疏，再生也更慢。

## 新区块分布

使用原版第四阶段产生的真实表土、树冠、仙人掌和水体。此时光照图尚未计算，生成阶段通过露天表面或林冠遮阴筛选，之后的生长轮询读取原生方块光照。高度按原版海平面计算，气温使用原版海拔修正。表中概率是每个区块尝试该物种的概率，满足条件的实际比例取决于地形与气候。
