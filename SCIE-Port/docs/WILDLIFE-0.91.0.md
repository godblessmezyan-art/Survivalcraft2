## 生成逻辑

旧实现曾因地形生成阶段创建实体卡住新世界，且开关长期关闭。本版移除旧静态区块队列、种子概率和只增不减计数；不在OnTerrainContentsGenerated做动物工作。项目加载后的SubsystemUpdate向原生SubsystemCreatureSpawn.m_creatureTypes登记四个Surface类型，每个Project去重注册。由原生游戏更新线程运行新区块播种和玩家附近随机补充，旧世界也可补充；不是“每区块固定8%/15%”。

共同条件：Living环境、原生设置允许生物生成；已加载并完成地形内容的区块，草土/泥土支撑，地表露天，两格空气，非水、非屋内、非树叶顶部；高度2–120（原生另收紧至>3）。原生还检查亮度、地表空间、玩家视距/距离、全局与局部生物数量。海岸距离不额外限制。温度/湿度为原生0–15编码，不是摄氏度。

权重参与原生所有合适物种的加权抽签，不能解读成百分比；世界设置会改变原生尝试间隔。每个游戏时间帧四种动物合计最多新增2只，每组逐只复核数量。原生单只位置尝试至多50次；没有扫描全地图或独立定时器。按原生已登记的当前活体实时计数，死亡或移除后空位恢复，跨世界不保留计数。自然生成ConstantSpawn=false，创造生成器保持true；所有既有AutoDespawn=false保持，离区保存/恢复沿用原生。上限包含手动生成的同种活体，但手动创造生成器本身仍可超限放置。

联机：Local/Server可执行生成；Client在适宜度和执行入口均返回0，由主机通过原生实体/行为/掉落同步。没有新网络包、没有客户端直接创建实体。手动生成器沿用既有主机/单机限定行为，普通客户端的手动点用仍不支持；自然出现的动物由主机同步。

## 行为与鸡蛋

- 狐狸：原生游荡、避火、犬科食肉AI；LandOther掩码、非玩家追逐概率0.35，可追兔/鸡以及其它原生LandOther，非“只识别兔鸡”。不主动把Human当猎物，受击仍可反击。近战伤害降至1.5。吃掉落肉/鱼；原生犬科声源保持。
- 兔子：原生低头觅食、群居、逃跑，新增5格避人；EatPickableBehavior对Grass/Fruit因子1，能寻找并吃掉落的草、花及果蔬。低头啃草为原生动画，不删除草皮或玩家种植方块；无新地形写入。仍用原生四足步态，未实现专门的兔式跳跃或繁殖。
- 鸡：原生双足行走、低头啄食、避人/逃跑；吃Grass/Fruit/Bread类型掉落物，不飞行。原生LayEggBehavior平均每480秒获得一次下蛋意愿，寻位后站地约3秒产1枚；会被逃跑、其它高优先级行为、寻路失败打断，不能保证严格8分钟1枚。鸡蛋118/类型50，IsLaid=true，营养0.2，可走原生煮蛋与孵化逻辑；不增加第二个物品ID。类型50紧接原生0–49，避免原生FirstOrDefault对稀疏蛋表空项解引用。其它三种蛋类型显式-1，防止继承Alpaca蛋索引碰撞。鸡死亡掉1只原生生鸟肉和1羽毛，着火走熟鸟肉。新增蛋不显示到原版创造栏，手动生成用本工程生成器。
- 猫：温和游荡、3格避人、受威胁逃跑，吃掉落Fish/Meat；无ChaseBehavior，不攻击玩家、不宣称已经驯服/跟随。Category=LandPredator仅用于避免被狐狸LandOther掩码当作猎物。兔/鸡/猫清空继承的牛叫，未伪称有专属录音。

此版动物行为使用目标原生组件，不新增技能特效，不触发神器PixelFX/图标或属性例外。
