# 地质奇景 0.99.0

支持大陆、岛屿和增强地形。地貌按世界种子和 192×192 格区域选址，每个区域最多形成一处。岩层、山体和洞道可贯穿多个区块。坐标、地表高度、海岸、温度、湿度和高差决定选址，实际出现率因地图而异。

## 存档与验证

原生第三阶段结束后规划地貌，第四阶段再处理原版动植物和液面。每区块独立推导同一座地貌，只处理本区块，单列检查及写入最多 58 个高度格，完成本区块写入后标记为待保存。已写入存档的区块正常加载。旧世界未写入存档的自然地形可能重新生成，跨越新旧区块时可能只出现部分地貌。与 0.98.0 相同，主机、本地或服务端负责地形，联机各端使用同一版本。

面向 `Net_x25.01.17` 编译打包。依照用户亲自实测的安排，实际生成密度、水流、视觉效果、游戏内通行和多人同步等待实测。
