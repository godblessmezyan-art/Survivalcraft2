# 地形总览与盐晶工艺 1.8.0

荒野探险家的自然地貌包括 23 种跨区块奇景和 18 种小型地标。大陆、岛屿和 Better 模式在新生成区块使用这些规则。竹林生态、竹林小径和竹亭另有生成器。水幕沉殿和日阶神殿是两处独立的机关遗迹。

## 优化顺序

| 优先级 | 目标 | 检查项 |
| --- | --- | --- |
| 高 | 新旧区块交界的连贯性 | 在备份世界测环礁蓝洞、三桥天坑、冰川长脊和火山被旧区块截断时的样子。方案优先考虑在新区块内渐变收边，保留已有玩家区块。 |
| 高 | 路线与水体 | 用触屏和实际载具验证寒崖峡湾、浅海礁道、海蚀拱门的通航，实测地下河、蓝冰洞和火山熔岩洞的进出。检查瀑布、蓝潟及潮缘礁池在水体更新后的形态。 |
| 中 | 可遇性与重复度 | 统计多种子、三种模式下各类实际落地数量。小地标分别统计抽签、邻块排除和选址拒绝，判断是否应扩大备选范围或按环境筛候选。 |
| 中 | 新区块生成开销 | 真机记录新区块地形阶段耗时。区域奇景的选址在每个区块重复计算，可测量同区域复用结果能节省多少，并验证负坐标和不同探索顺序。 |
| 后续 | 地貌辨识度与采集 | 区分干峡谷、冲蚀沟壑和红岩窄缝的剖面与用途，以及冰塔林、雪线风脊、雪脊冰阶的行走体验。冷区可做蓝冰灯罩，浅海可做贝壳马赛克，岩溶区可做钟乳石装饰。 |

`HighVolcano` 大陆模式固定抽样的 4,624 个区域中，环礁蓝洞和浅海礁道各选中 1 处，白沙蓝潟 2 处，寒崖峡湾 3 处。该样本可用来复测稀有地貌，其他种子的分布需要另测。

## 已新增的物品与方块

- **盐晶 `898/DATA0`**位于「自然与生物」。一块白盐壳 `1012` 合成两枚，盐晶仅作为材料。
- **盐晶灯 `899/DATA0`**位于「建造与家居」。工作台上排依次放盐晶、火把、盐晶，中排中央放柱状玄武岩 `1006`。灯是全高立方块，使用原生 12 级光源，挖下回收一块。已有世界采来的白盐壳和玄武岩也可使用。

盐晶图标和盐晶灯使用原创像素纹理。`python SCIE-Port/scripts/New-GeologyAtlas.py` 可重建图集，旧 12 张材质的像素保持一致。两件物品的 DATA 均为 0，联机各端使用同一构建。Android 7723 实际画面、触屏合成和联机同步待验证。
