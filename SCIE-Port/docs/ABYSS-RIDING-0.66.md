# 刻尔柏洛斯骑乘、军势追击与次位面恢复 / 0.66.0

2026-11-01，基于main `1af697e` / 0.65.3；工作区干净，回退点`backup/abyss-0.65.3-before-cerberus-riding`，旧包保留。本版只提交本地main，不自动推送。按用户此前安排，未运行自动化行为套件、GPU、游戏或联机会话；以下运行行为是代码实现，Android验收仍待用户实测。

## 使用

1. 召唤刻尔柏洛斯，或重进世界加载已有契约。靠近身体侧面、面向躯干，使用原生骑乘按钮上马；原生搜索要求坐骑基本静止且座位距眼睛约2.5格内。主人面向坐骑靠近时，坐骑暂停让路动作，方便上马。
2. 上马后出现文字按钮「自动追击」，默认关闭；不要求一直拿着镰刀或保持死亡形态。按钮复用神器HUD的查看锚点/障碍避让，安全位置不足时隐藏；军势面板底部也有同一设置。它是骑乘设置按钮，没有新增技能图标。
3. 开启后自动寻找、追击并攻击敌人；手动前进/后退、转向、跳跃时立即优先使用骑手控制，停止手动输入约0.85秒后恢复自动追击。观察视角不会被当作移动输入；打开面板/对话框时暂停自动移动。手动控制期间仍可自动攻击附近、正面的敌人。
4. 关闭后骑乘状态停止军势自动攻击；下马后恢复普通护卫AI。每只契约坐骑单独保存开关，旧记录默认关闭。夜魇战马也支持该开关。只有主人实际骑在自己的坐骑上才可切换。
5. 军势列表选中一只后，右下角按状态显示「召出所选 · 单只」或「收回所选 · 单只」。上方仍有「全部收回次位面」「全部召回现世」。单只操作不消耗新建召唤的30秒冷却，不会新建另一份契约；待加载记录不能直接操作，有乘客的实体不能收回。

## 现世与次位面治疗

现世中的全部契约生物（含专属召唤和普通转化）不再自然回血。死亡蔓延在原有一次扩散结算时为每只己方契约恢复**97点实际生命**，最多达到其生命上限，替换原来的回满；现世、次位面和暂未加载的契约均覆盖，不复活已死亡实体。战马44、猎犬37生命上限，因此低血量时仍可能被97点治疗回满；刻尔柏洛斯444生命，上限不变。

次位面生物没有实体更新，每累计**2秒世界运行时间回复1点实际生命**。只统计隐藏时段，暂停/退出世界不累计离线现实时间；不足2秒的进度随契约保存，在现身和再次收纳间也保留。血量变化沿用已有生命列同步，满血时不额外广播每次计时。召回时把次位面血量和排队治疗应用到实体，不会恢复旧快照的低血量。单只收回和全部收回使用相同规则。

目标原生ComponentHealth会对NPC自动调用Heal，该方法非虚方法、没有专用治疗Hook。使用已存在的SubsystemUpdate Hook：实际目标在组件全部更新后调用此Hook，只对当前最多24只契约限制非授权生命增长，不改野生生物、玩家、世界恢复系数或组件类型；本功能97点治疗和次位面现身显式更新允许的生命值。伤害与此治疗仍全部在主机执行。旧存档HealOnReturn待回满标记迁移成一次97点治疗；隐藏实体优先读取原快照受伤血量，避免继承旧面板的预告满血。原生伤害与自然治疗恰好同帧时，净下降部分沿用原生计算；本实现限制逐帧净回血，并未重写原生伤害方法。

## 原创模型与座位

保留原三头原创模型、贴图、7骨/7网格/6628三角形，没有添加超过原生容量的骨骼。给相同实体模板增加原生Mount和继承原生SteedBehavior的ComponentCerberusSteed；后者显式启用原生坐骑行为，解决模板名不是`_Saddled`时原生默认禁用的问题。

座位MountOffset=`0,2.08,0.5`，原生人物RiderOffset的Y为-0.71，对应人物身体根位置约`0,1.37,0.5`，腰部落在背甲上。DismountOffset=`1.8,0.3,0`，复用原生侧向遮挡检查和下马插值。原生骑姿基础上，将两腿分别向外旋转0.85弧度以跨过宽背；身体/手臂姿态保持原生，衣物模型同时修正。复用已有ModelShaderParameter预绘制Hook和实际原生骨骼接口，按帧缓存，避免多相机重复叠加；没有新Shader或隐藏角色。

上述是坐标/接口实现，实际人物穿模、衣物、第一/第三人称、上马和下马必须由Android画面验证，未把静态资源解析称作实机通过。

## 四格跳跃

目标为干燥平地约4格上升/越障。模板JumpSpeed名义值10；实际组件根据目标原生的每帧顺序（重力`-10*dt`，再垂直AirDrag，再移动）和当前步长做有界14次二分，计算约4.05格的理论上升，留0.05格越障余量。正常每0.5秒检查，起跳时可立即更新，步长/阻力变化不明显时复用值。无需数组、粒子或地形修改。

坐骑FallResilience改12；骑乘期间骑手落地耐受最低12，使用本功能自有增量，下马/退出恢复。仍保留大落差摔伤，没有全程无敌。水中、斜坡、顶棚、帧率波动及移动平台会影响实际跳跃；CPU公式不能替代真实4格平台测试。生命444、伤害37、间隔1秒、移动参数7保持。

## 跟随与让路

旧代码向主人位置持续寻路并停在2.5格，原生1800质量的大身体靠近时容易推挤。新版空闲时距离主人超过9格才开始跟随，到约7.5格内停止；寻路终点放在主人后侧5.5格并按契约键分开左右位置。大身体的召唤/归队/现身搜索半径改为6格，小身体4格。

靠近任何玩家时逐帧刹掉朝玩家方向的水平速度，停止原进逼路径，尝试向外侧安全位置让路；主人面向坐骑靠近时停步，方便骑乘。近身未骑乘实体临时采用较低的碰撞质量，离开玩家后归还自有修改；客户端同样处理自身碰撞所见的契约实体，避免只改房主表现。挂接/骑乘实体不做此质量软化，属性不写入存档。仍保留原生实体碰撞；狭窄地形、多只生物交叠时的效果待真机确认。

## 逃跑目标追击

旧AI每次都在主人24格内重新选目标，逃出24格便被丢弃；中立生物从追击切换为逃跑后也可能失去敌对标记。新版新目标仍从24格内获取，已确认目标可保留到主人64格范围，最多20秒追击租期，攻击及有效护主威胁刷新租期。原生逃跑行为本身不再立即解除已确认目标。

超过范围、租期、目标死亡/变成友军/受保护或失去安全条件时结束追击；卡住6秒后尝试安全归队，未骑乘闲置远离48格仍可归队。被骑乘时不执行归队传送。搜索仍共用每帧128候选、24次伤害预算，处理顺序轮转；不扫描全地图。追击使用完整移动参数，普通跟随降低移动比例。

## 联机与生命周期

主机决定目标、攻击时刻和伤害，继续保护所有玩家、友军、玩家承载体及领地。原生SCNET对骑乘实体使用骑手客户端移动物理，因此主机每0.25秒只向实际主人骑手下发移动/停驻计划；普通客户端只执行该计划的移动，不产生伤害。计划校验来源、世界、归属、修订、坐标和期限，1秒过期后停下等待；本地手动输入立即覆盖，并发主机暂停通知。近战转身同样只在物理归属端应用，手动控制时清除自动转身。

骑乘模式关闭、下马、死亡、掉线、换服务器、退出世界时停止本功能路径/控制，释放HUD、落地耐受与临时碰撞属性。收纳/解除继续禁止移除有乘客的实体。生命面板、次位面、七只上限、每位主人唯一三头犬和转化后1点生命保持。

252保留原字节布局：Kind3 Flags64标识RidingAuto；Kind9为主机移动计划（Flags0手动、1追击、2停驻）；Action11为骑乘模式切换，Action12为骑手手动输入通知，Action13/14携带既有Target契约键分别召出/收回单只。请求仍经角色/连接/世界/序列验证，模式切换还核实实际骑手与契约主人；单只操作必须匹配主人，Target=0拒绝，不会误变为全部操作。契约仍读v1/v2、写v2，增加可选RidingAuto（默认false）、RegenCarry（不足2秒进度，默认0）、PendingHeal（未加载实体待治疗点数，默认0）；247/249/250/251和星门格式不改，无新物品/方块/包ID。各方必须统一0.66.0，旧客户端没有新坐骑组件与控制语义；回退到旧版本应恢复该版本对应世界备份，旧版不认识新治疗元数据。
