# 奇景候选 1.5.0

跨区块奇景增至 19 种。每个 192×192 格区域最多生成一处，保留原有 83% 的选址入口和四个尝试位置。每个位置先检查原生高度、海岸距离、温湿度和起伏，再从适合该位置的普通奇景中等权抽取。火山保留单独的抽签比例与高地出口校验，选址未通过时普通奇景仍可落地。只符合新增地貌的地点作为备用位置。浅海台地同时符合黑沙柱岩海岸与环礁蓝洞时等权抽取。

| 新奇景 | 选址与形态 |
| --- | --- |
| 三桥天坑 | 暖湿内陆高地。三道天然灰岩桥跨过带有两段拓宽盆地的峡谷，桥下留出通行空间。峡道弯度随种子变化。参照[武隆喀斯特](https://whc.unesco.org/en/list/1248)。 |
| 白沙蓝潟 | 暖湿、低起伏的近海陆地。弯月沙脊之间有两至三座青蓝色浅池。各池与完整围岸位于各自的单一区块，围岸预检失败则跳过整池。参照[巴西伦索伊斯－马拉年塞斯](https://whc.unesco.org/en/list/1611/)。 |
| 环礁蓝洞 | 暖水浅海台地，浅色礁缘留有一侧缺口，中心岩溶沉井可深入约海平面下 27 格。只修改原生水下地表列，避开水幕沉殿的选址范围。参照[伯利兹大蓝洞](https://whc.unesco.org/document/133369)。 |
| 冰川长脊 | 寒冷的内陆高地。蓝冰舌沿地形轴延伸，两侧有连续碎石冰碛和花岗岩坡。参照[瑞士少女峰－阿莱奇](https://whc.unesco.org/en/list/1037)。 |

相同种子从不同方向进入同一区域，选址与类型一致。新版应用于大陆、岛屿和 Better 模式的新生成区块。已有区块照常加载，新旧边界可能只显示奇景的一部分。固定目标测试及坐标见 [测试记录](TEST-RESULTS.md)。Android 7723 和真实联机待验证。
