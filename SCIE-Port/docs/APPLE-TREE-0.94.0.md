所有五项在创造栏「自然与生物」中可找到。砍下树基可获得原木和一棵苹果树苗。普通树叶使用原版树叶的工具等级和掉落逻辑。玩家单独摆放的树叶没有生长归属，其中结果树叶可采一次。移除附近支撑木材后，原生木材子系统会让树叶按原版规则衰败。

## 成树和结果

单机或主机复用同一株原生 TerrainBrush 一次生成 3 格原木和 18 格树叶。人工栽种受区块加载、光照、温湿度、土壤与空位约束，自然生长使用现有生态生成位置。春季，树干完整且树基有合适土壤的苹果树可以补回原树形中的空缺叶格。秋季采过的果枝等待下一生长季。关闭季节变化的世界继续按环境和轮询再生。

## 升级已有世界

旧 939 苗龄及苹果 940 沿用。旧存档中的 939 树基、树干和有效树叶在加载后的主机轮询中逐格原地迁移。可继续读取尚未迁移的相邻树格，因此迁移可以在不同区块和扫描帧间完成。旧挂果和采后标志随树叶保留。各联机端需要同一版本。

Apple XDB 绑定和 GUID 保留。978 的低两位为原版木材朝向，自然生成且可恢复树叶的树基使用 bit 2，掉落或再放置时清除。979/980 由旧树叶数据位记录归属偏移、发育阶段与采后状态，创造栏初始 DATA 为 0。978–980 已检查固定版本原版方块及本仓库自定义方块，第三方外部模组仍可能占用相同 ID。
