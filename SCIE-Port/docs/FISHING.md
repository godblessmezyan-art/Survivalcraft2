# 钓鱼 0.91.0

## 操作

1. 手持鱼竿，对准水面点按使用。浮漂落在至少四格连通的水面上，落点至少两格深，抛投最远约十二格。
2. 普通鱼等口 12–22 秒。水纹靠近以后，等浮漂明显下沉、听到水花声，在三秒内提竿。在触屏上可以点按提竿，再按住收线，也可直接长按。键鼠用右键。
3. 普通鱼持续收线 3–5 秒。松手可以暂缓，重新按住继续。换手持槽位、走出十六格、死亡或钓点失去水深会结束这一竿。
4. 收完鱼线得到一份原版生鱼，可用现有熔炉烹饪。背包容量不足时，多出的生鱼掉在脚边。

鱼竿右边紧邻的快捷栏放一叠「小麦种子」或「野生小麦种子」即可挂饵。有效咬钩时扣一枚；提前收竿可留住种子。挂饵把等口缩到 9–17 秒，并有 25% 的机会遇到大鱼。大鱼会挣扎两次，鱼线变紧时松手，线松后继续收，钓上给两份生鱼。鱼竿在快捷栏最右格时按无饵处理。

## 联机实现

- Local 直接执行同一套钓鱼逻辑。普通 Client 通过包 236 发送抛竿目标、提竿及按住/松手。Server 从原生连接取得对应玩家，复核鱼竿、水深、水面面积、视线、距离、会话编号和所处阶段。每名玩家至多有一竿，客户端提供的输入不推进主机计时。
- 基础提竿窗口三秒。远端额外有 0.65 秒传输余量。收线按住消息每 0.2 秒刷新，超过 0.85 秒未收到刷新便停止收线。收线阶段最多十六秒。会话结束或玩家离开时清理。
- 主机用原生背包逐件收取方法结算原版生鱼，余量用原生掉落物。背包与世界掉落走游戏已有同步，包 236 返回浮漂阶段、拉力状态和结算反馈。会话从主机状态移除后才进行发鱼，结束的会话不能再次结算。
- 各端安装 0.91.0。包号和 20 字节结构沿用旧版，旧的客户端提交成功请求已停用，混版钓鱼不支持。鱼竿 972/DATA0、已有配方和数据库 GUID 沿用。临时鱼线、鱼漂和鱼出水效果由视图绘制，不添加世界实体或存档数据。

## 验证

环境、Windows Release、包内容及实测情况见 [测试记录](TEST-RESULTS.md)。Android 7723 与真实房间按同一包安装后，重点检查手机触屏提竿、两人同时钓鱼、收线期间离开、距离和水域变化，以及鱼肉能烹饪和满包拾取。
