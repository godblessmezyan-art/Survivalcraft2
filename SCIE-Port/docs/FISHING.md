# 钓鱼 0.94.0（沿用0.92.0蓄力流程）

## 操作

1. 手持鱼竿，按住使用键蓄力，转动视角瞄准，再松手抛投。键鼠用右键，触屏长按游戏画面，和原版投矛使用同一套瞄准输入。蓄力越久，浮漂飞得越快，约 1.15 秒蓄满。瞄准时用虚线预览弧线，能钓的水面会有落点圈。
2. 松手时鱼竿会向前甩并回弹，鱼线随浮漂飞行。浮漂会被地形截停，只有从上方落进相连、足够深的水域才开始等口。抛投上限约 18 格，实际距离受蓄力、瞄准角度和岸边高度影响。
3. 普通鱼等口 12–22 秒。浮漂下沉后，在 3 秒内提竿，再按住收线 3–5 秒。触屏可以点按提竿再按住，也可以直接长按。松手可暂缓收线。换手持槽位、离开钓点超过 22 格、死亡或水太浅会结束这一竿。
4. 收完鱼线得到一份原版生鱼，可用现有熔炉烹饪。背包容量不足时，装不下的生鱼掉在脚边。

鱼竿右边紧邻的快捷栏放一叠「小麦种子」或「野生小麦种子」即可挂饵。有效咬钩时扣一枚，提前收竿可留住种子。挂饵把等口缩到 9–17 秒，并有 25% 的机会遇到大鱼。大鱼会挣扎两次，鱼线变紧时松手，线松后继续收，钓上给两份生鱼。鱼竿在快捷栏最右格时按无饵处理。

## 联机实现

- 包 236 沿用 20 字节布局。客户端发送蓄力开始、释放时的方向和中止信号。主机用自身时钟记录蓄力，用玩家的实际位置和原生地形碰撞求出发射点、速度和飞行时间，再广播给房间。客户端的轨迹预览只用于瞄准。
- 当浮漂到达落点时，主机复核水域和沿途地形，再启动等待。每名玩家至多有一竿。提竿、收线、消耗鱼饵和发放生鱼由主机判定。背包和世界掉落沿用原生同步。
- 基础提竿窗口 3 秒，远端另有 0.65 秒传输余量。按住收线消息每 0.2 秒刷新，超过 0.85 秒未收到刷新则停止收线。收线阶段最多 16 秒。切杆、超距、离线或会话结束时清理。
- 房主和玩家均需安装 0.94.0，混版钓鱼不支持。鱼竿 972/DATA0、配方和 XDB 用于原有存档。浮漂和鱼线是会话画面，不向存档添加实体。

## 验证

环境、Windows Release、原生地形、收线、背包和隔离渲染结果见 [测试记录](TEST-RESULTS.md)。Android 7723 和真实房间需要用同一版本实测。重点是长按蓄力后转向、松手甩竿，以及旁观玩家看到的动作和落点。
