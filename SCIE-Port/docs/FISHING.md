# 钓鱼玩法（0.86.0）

## 物品与获取

- 「鱼竿」972/DATA0，不可放置，最大堆叠1，近战伤害0，归 `SCIEPort.Tools`（实用工具）。
- 程序化2×2配方：木棍×1 + 线×2（`stick`+`line`+空+`line`）。材料名在运行时由 `BlocksManager.FindBlockByTypeName("StickBlock"/"StringBlock")` 的 `GetCraftingId(0)` 解析，不硬编码材料ID。
- 无新增鱼类物品：产出原版生鱼 `RawFishBlock`，可直接走原版篝火/烤箱烹饪。

## 玩法流程

1. 手持鱼竿，面向水面点击（触屏等同使用键）。
2. 从视线起点沿射线每0.25格采样，最多12格；命中水格且该格水面高度≥0.5、下方一格仍是水时开始垂钓。
3. 等待2–5秒后咬钩：浮标位置播放原生水花粒子，提示「咬钩」。
4. 0.9秒窗口内再次点击收竿即成功：生鱼1–3条（70% / 25% / 5%）。
5. 窗口前点击为过早，窗口结束未收竿为超时；两者都提示「鱼跑了」并冷却1秒。
6. 切换手持物品、死亡、或与浮标距离超过20格时会话自动结束。未命中水面提示「此处无鱼」。

浮标是逻辑位置（水面坐标），视觉仅用原生水花粒子，不创建实体或新增存档对象；退出世界不保留任何钓鱼状态。

## 联机（主机权威）

- 客户端在本地判定收竿时机，成功时发送包 236（`FishingCatchPackage`，Request/Result，负载20字节：Kind/Caster/Cell/Sequence/Count）。
- 主机收到 Request 后校验：请求者仍手持鱼竿、目标格仍是水、与目标格中心距离≤16格、该玩家限流（最小间隔0.8秒、每分钟18次）。校验通过由主机把生鱼写入该玩家背包，并发送 Result 回执；失败回执 `Count=0`。
- 鱼获经主机背包槽位变更走原生物品同步，客户端不直接改背包；背包满时由主机在玩家脚下生成可拾取物。
- 回执到达客户端后播放水花并提示「钓到鱼」。包处理会校验来源连接：主机只接受本连接玩家且 `Caster` 与实际实体一致；客户端只接受 `From == Server`。
- 单机/主机本地游玩不发包（`CommonLib.WorkType != WorkType.Client` 直接授权）。仅主玩家触发交互（`IsMainPlayer`）。

## 限制与边界

- 只识别表层水格（`GetLevelHeight ≥ 0.5`）且要求下方仍是水；浅水、流动边缘和悬空水幕不能垂钓。
- 不在水中、岩浆、非水方块或超过12格处起竿；无鱼群/生态判定，任意合规水面均可。
- 会话只跟踪浮标坐标，不跟踪水体变化；等待中水体消失不会中断，成功时主机仍会复验目标格为水。
- 服务端/主机不模拟咬钩广播：其他玩家看不到他人的咬钩提示，只能看到最终水花。
- 无钓鱼等级、鱼种、鱼饵、耐久消耗或钓鱼战利品表；这些不在本版本范围。
