# 钓鱼玩法（0.86.2）

## 物品与获取

鱼竿972/DATA0为普通实用工具（非神器），不可放置、堆叠1、近战伤害0，归SCIEPort.Gear（装备与工具）；不增加神器被动。保留木棍1+线2的2×2程序化配方，按实际Block.GetCraftingId解析材料，产出原版RawFishBlock，原生烹饪保持。

## 触屏与水面

- 点击使用下竿，再次点击收竿。落点沿使用射线进行三维逐格遍历，计算与实际流体水面的交点；从完整方块值ExtractData→FluidBlock.GetLevel→GetLevelHeight，禁止把完整方块值当水位索引。
- 最远12格；原射线未命中且方向接近平视时，按Y方向减0.15、0.30依次小幅向下尝试。首次遮挡立即停止，不穿墙、不从背后找水。最多3条射线，每条最多64格；坐标有限且XZ绝对值≤10000000。
- 一格深水、人工池塘及有非零水面的流动边缘允许垂钓。水格上方须为空气，地形区块须Valid；水侧面、覆盖水、岩浆、水下起点不能当水面。本轮保留生鱼1–3条及70/25/5%分布，不引入实体鱼扫描或新鱼种。
- 等待2–5秒（20ms刻度），咬钩后1.35秒内收竿成功。失败冷却1秒、成功0.35秒。浮标/鱼线/水纹持续可见，咬钩下沉并播放原生水花与短提示音；无常驻教程。失败分别显示“落点受阻”“水域未就绪”“抛向近处水面”，不再统称“此处无鱼”。
- 换物品、死亡、离浮标超过20格、水面消失/覆盖或水位变化≥0.15格时收竿；退出清理。暂停使用GameTime，不用墙钟推进。会话不写存档。

## 联机

各端须统一0.88.1；旧版本混用不支持。仍使用包236和20字节布局（Kind/Caster/Cell/Sequence/Count），新增语义如下：

| Kind | 含义 | Count |
|---|---|---|
| 0 | 收竿请求 | 忽略 |
| 1 | 最终回执 | 鱼获0–3，0为失败 |
| 2 | 抛竿请求 | 忽略 |
| 3 | 主机开始回执 | 等待时长编码，wait=2+Count/50，0–150 |
| 4 | 取消 | 忽略 |

客户端先显示浮标，收到主机开始后计时；主机创建等待时间与独立会话，校验连接玩家、鱼竿、水面、≤12.75格眼部距离与无遮挡；收竿再次校验同会话/序号/水格和时机。序号按连接单调递增并支持uint回绕；旧/重复抛竿不重开，收竿在奖励前消费会话，早/晚失败也不能重复提交。普通客户端不直接写背包。

主机允许最多1秒额外迟到（仅晚端，不提前咬钩），覆盖往返网络与更新排队延迟；超过该预算不保证成功，Android及真实延迟体验待验证。客户端开始/结算回执8秒超时，不永久卡住。结果绑定Caster/Sequence/Cell，过期/重复回执忽略；来源复用ServerConnection.IsServer，避免原生Server/Clients[0]对象不同导致丢包。

包处理仅拷贝到加锁队列，容量128、每更新最多16项，地形检查/背包修改/粒子创建在更新线程执行。最多64活动会话、128连接历史；断线/退出释放，历史保留到连接离开以阻止同会话重放。主机限流最小0.8秒、每分钟30次，与至少2秒等待相配。远端主机还检查仍属于该连接的玩家。背包分槽填充，剩余鱼获才掉落脚下，不丢失半满槽位的余量。

主机显示本机所知会话，普通客户端只显示自己的浮标；未新增全房间浮标广播或持久实体。

## 兼容性与验证

仍为Net_x25.01.17、net472、API1.42、SC2.4.10.6，统一SCIEPort.dll与包；鱼竿972、原配方、FishingBehavior XDB/GUID、原始鱼/水/存档保持。新增IDrawable/DrawOrders=106，沿用既有原生Draw接口，无新增加载器Hook。无新运行资源或外部依赖。

运行随机数使用Engine.Random.Float/Int，避免留存Android BCL快照中缺失的System.Random.NextDouble；新增Test-FishingAndroidBcl.ps1可对最终DLL和负对照重跑。

测试覆盖真实落点算法（浅水、薄水层、流动水位、遮挡、负坐标、水平辅助、距离、无效输入、未加载与采样预算）、规则与主机轮次/重放/网络迟到；原生测试对最终DLL调用64组完整水格解码，并对5种包语义做真实20字节往返。实际命令/包哈希见TEST-RESULTS。Android7723、不同分辨率与真实Local/Server/Client均待验证，不能用离线或编译代替实机。

## 0.86.2 表现选型（实现前）

鱼竿是普通实用工具。本轮已阅读PixelFX规范、固定目录和当前接入记录；目录候选water/ripples、water/splash只有索引证据，未检查候选上游帧或做新导出，不声称已验证其素材。现有water-wave是一次性大范围水浪，不适合持续的小浮标。选用原创立体浮标/鱼线/小水纹和原生WaterSplashParticleSystem，无新外部资源、图集或技能图标。几何随游戏时钟更新，每相机最多8个浮标、64格距离，空闲不绘制，不反复创建粒子维持状态；切物品、死亡、水面消失、超距、超时和退出清理。
