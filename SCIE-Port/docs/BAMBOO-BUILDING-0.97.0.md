## 竹林地标

- 已成功生成竹林的新区块有 58% 的机会尝试铺小径。碎石小径长 7–13 格，各步最多升降一格，可以绕开竹株、树木和其他植物。
- 同一竹林区块有 40% 的机会尝试寻找竹亭位置。内陆水面须有至少三个齐平相邻的水格，水位距离亭址基准地面最多三格，距海岸线至少 12 格。河岸和满足同样条件的内陆湖岸都可以出现。实际出现率取决于地形、植被和能否找到通向竹林的步道。
- 竹亭有 3×3 竹平台、四角立柱、竹栅栏、竹门、双层竹编屏风和 5×5 木瓦坡屋顶。门朝陆地，2–13 格的碎石路接回竹林边缘。
- 竹亭及道路先完成同区块内的选址和路线检查，再写入新区块。每区块最多一组地标。生成使用空位和普通土面，可清除铺设位置的原版杂草，保留现有水体、树木和竹株。旧世界仅在探索新生成的区块时出现地标。

## 安装与验证状态

目标是 Survivalcraft NET `Net_x25.01.17`。升级时替换旧的荒野探险家安装包，联机各端使用同一版本。新方块编号 1002–1004 可能与第三方模组冲突。竹子 932、竹材 933 和竹笋 1001 的编号与生长数据沿用 0.96.0。

本轮编译并打包，由用户实测。可先在「建造与家居」拿取三件建材，试摆栅栏和原版栅栏相连、打开竹门，以及转向摆两堵屏风。自然地标可在暖湿低地的新区块寻找，沿内陆水岸探索更容易遇见竹亭。竹笋移栽、采竹后再长、Windows/Android 游戏画面与真实联机均待实测。
