# 0.94.0 奇幻地形：沉船、飞艇与浮空岛

固定目标：SCNET `Net_x25.01.17`、net472、API 1.42、SC 2.4.10.6。功能属于荒野探险家 / `SCIEPort`，在原生地形第四阶段和植物之后生成；不依赖 Builder Assistant，也不改变其蓝图材料表。

## 生成层

- `PlantTerrainGenerator` 包装原生 `ITerrainContentsGenerator`。`GenerateChunkContentsPass4` 先调用原生生成器，再调用植物生态，最后调用 `SceneryGenerator`。三段各自捕获异常，互不阻断。
- `SceneryGenerator` 只在 `CommonLib.WorkType != WorkType.Client` 运行；`TerrainGenerationMode.Nihility` 世界不生成。客户端始终只接收主机或本地原生地形。
- 规则层 `SceneryRules` 只输出世界坐标体素，不引用引擎类型；引擎适配层只把落在当前 16×16 `TerrainChunk` 内的体素写入 `Terrain.MakeBlockValue`。因此同一世界种子、同一站点在不同区块生成顺序下结果一致。

## 选址规则

- 世界按 112×112 单元格划分。每格以中心 ±24 格抖动得到锚点，用世界种子与单元格坐标的 FNV 混合流决定类型、尺寸、朝向和破损噪声。
- 海洋：锚点地表低于海平面且水深至少 8 格时，76% 生成沉船。船体局部高度按可用水深截断，最高体素不超过海平面下 1 格。
- 陆地：锚点地表不高于 150 格时，42% 生成飞艇，32% 生成浮空岛，其余留空。飞艇最低离地 26 格，锚点不低于 136；浮空岛最低离地 26 格加底部深度，锚点不低于 140。两者顶部都不超过 246。
- 每区块最多返回 4 个与水平范围相交的站点；同一站点由多个区块分别生成时，各区块只写自己的部分，不重复写其它区块。
- 站点的朝向为四分之一旋转，锚点抖动和旋转在区块间稳定。

## 安全写入

- 只覆盖空气。沉船允许把水替换为船体方块；任何原生固体方块、矿石、树木、家具或其它场景方块都不覆盖。
- 写入 y 限制为 1..254。写入前不删除地形，不触发流体更新或方块行为；没有变更计划、撤销记录或实体生成。
- 未注册场景方块时整段跳过；缺少原生方块常量时同样跳过，不影响原世界加载。
- 场景生成属于世界初次生成，没有玩家发起的批量写入，因此不设撤销账本或取消入口；任一异常由独立捕获记录，已写方块保留，未写方块在后续生成中可补齐，原生地形和植物不受影响。
- 成本由站点尺寸和每区块站点上限约束，不进行跨区块扫描或全图遍历。

## 场景形态

- **沉船**：中空椭圆船壳向首尾收窄，带甲板、舱口、两根桅杆、横桁和破损帆；舱内有宝箱，船周散落木板。整体按 `SlopePercent` 倾斜，破损噪声开洞，始终位于海面以下。
- **飞艇**：椭球气囊带三款蒙皮、内部木环肋和蒙皮破洞；下方吊舱含船壳、甲板、玻璃窗、门、宝箱和云晶灯，木柱连接气囊；尾部有木板尾翼、破帆、黄铜螺旋桨和顶部旗帜。
- **浮空岛**：云石倒锥基座，顶部云石、泥土和草皮，中央一棵原生橡树，边缘与顶部生成青色或紫色云晶。
