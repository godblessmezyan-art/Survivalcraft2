# 共享永久星门 · 0.59.1

按用户确认的规则：所有星门都是永久星门，可以命名、删除并随世界保存；多人共享同一份记录，所有玩家都有建立、改名、删除和管理权限。创建者字段只记录来源，不再限制管理权限。目的地从已经记录的星门中选择，不输入远程坐标。每位玩家独立选择，同一座门可同时通往不同目的地。

## 两种入口

1. **随处施法**：持有阿比斯，点击星门技能，打开共享列表。选择目的地，点击“前往所选星门”，在附近空地建立一座永久出发门，走入后传送。出发门用完仍保留；附近缺少安全空间或数量已满时明确提示，不建立临时入口。
2. **操作实体星门**：靠近并点击门面打开同一列表，无需持有阿比斯。选择另一座门并点击前往，走入当前门完成传送，不额外建立出发门。

列表每页五项，显示名称、实际中心坐标和距离。可翻页、刷新、选择、保存名称、删除及建立永久星门。名称最多32字符；允许同名，坐标可区分。删除需要两次点击确认，权限对房主和普通玩家一致。建立后目标、名字等记录由主机世界的正常保存/退出机制写入存档。

**建立永久星门（0.59.1修复）**：提前瞄准6格内地面时优先按该落点建立；没有命中地面时，按视角水平朝向在身前3/4格处各搜索左、中、右，最多6个候选点，保留输入的名称。垂直仰视时以身体朝向确定身前。明确瞄准的地面不安全时直接报错，不悄悄改到别处。所有候选仍须通过6格距离、视线、有效区块、3格宽实心地面/4格高空气净空、领地、生物/移动方块和现有星门间距检查，不修改地形。

打开/刷新列表与修改操作分别限流（刷新0.25游戏秒、修改0.15游戏秒）；读取列表不占用建门窗口。限流、名称无效、空间不足和存档不可用均返回明确结果。面板在列表上方单独显示反馈，自动收到共享快照时保留建门结果；成功后关闭面板即可看到门。断开主机时按钮请求直接显示未连接，不停留在“正在处理”。

## 存档和选择

- 保留v1存档结构、WorldId、星门Id、Owner、位置、朝向和Active字段；旧记录可读取，坏记录保留原文并停止修改，不清空存档。
- 旧的全局Target字段只用于历史格式兼容；新版传送使用玩家自己的Source/Target选择，改名、刷新不会改变其他玩家的目的地。旧门使用前需要重新选择目的地。
- 选择保留60游戏秒；到达、死亡、断线、实体/连接变化、删除源门或目标门均清理相关会话。离开门口后才能再次触发，落点在目的地门前的安全位置。
- 默认世界上限仍为12，可通过已有VoidPortalLimit配置至64；达到上限后删除不需要的门或使用已有门，不自动替换旧门。
- 改名和删除允许在共享面板操作任意已记录星门。打开面板的入口是持有神器或靠近任意星门，不要求靠近被管理的那一座。创建和传送仍检查原生领地、区块和空间条件。

## 多人同步

新增250号包，240–249不变。所有客户端的操作由主机验证连接当前实体和请求序号，在主线程更新共享记录；所有玩家权限相同。并发改名按主机收到并接受的最后一次操作生效。重复请求、旧连接、伪造实体与非主机快照被拒绝。

快照拆成开始、逐门记录和结束包，最多64门，完整接收后原子替换客户端列表；半份快照不覆盖当前记录。每包固定字段及最多384 UTF-8字节文本，队列上限256、每帧32条处理；每次同步最多向两个玩家发送，变更或加入时同步，不逐帧广播整个列表。玩家选择不会写进共享门记录。所有联机参与者须升级到0.59.1。

传送采用主机准备安全落点→拥有者客户端加载并验证→主机提交→客户端移动并确认→主机更新权威位置的握手。目的地和源区域在期间持有有界区块租约；多人同时抵达时预留各自的落点包围盒，避免重叠。客户端预加载直接使用已审计的TerrainUpdater排队位置，不广播虚假的原生玩家位置。成功/回退均重置原生NetPosition、NetVelocity及发送缓存；原生ReliableOrdered链路让确认之前的旧位置先被消费，避免下一帧被旧插值拉回。目标消失、空间变化、准备超时或断线会取消并回收会话；收到提交后的取消恢复出发位置。客户端输入锁有截止时间，迟到终止仍能纠正位置。

创建者以外的普通玩家也可修改、删除门；这些操作更改主机注册表，由主机存档，客户端不直接改写主机文件。此版不扩展普通客户端的阿比斯普攻和瞬狩协议。

## 验证范围

目标为固定Windows x25.01.17/net472。纯规则覆盖同源不同目标、删除一门只影响对应玩家、独立选择不受旧链接影响和存读档。原生程序集夹具覆盖250包无冲突、真实序列化、长度/UTF-8边界、普通非创建者权限、队列身份重检、重放拒绝、完整快照替换、主机身份、客户端预加载/提交/取消、旧插值重置及租约清理。

真实Android7723触屏、实际网络、图形与物理尚待验证。建议在可丢弃新世界按下列步骤验收：

1. 单人、房主、普通玩家分别平视打开列表后立即点击“建立永久星门”；确认身前建门、名称正确、面板显示成功。再提前瞄准地面建门、尝试低顶/无地面/领地/重复位置，确认拒绝时有可见提示且不产生残留门。快速刷新后建门不被吞掉，连续操作显示限流提示。各玩家互相改名、删除；退出保存后重进，名字/位置/数量保持一致。
2. 两人从同一门分别选择不同目标，确认各自到达；重复进入前先走离门口。
3. 从野外施法，确认建立的是永久门，返回列表可再次使用和删除。
4. 传送准备时由另一人删除源门或目标门；检查取消、恢复控制、无坠空、无错误落点。
5. 远距离尚未加载的目标、网络延迟、掉线、重连、死亡、关闭面板和退出世界；检查加载超时和会话/租约清理。
