# 石灰岩金字塔与环壁火山 · 1.7.0

## 金字塔

方形基座和四面浅色石灰岩包面共同收向塔尖。北侧石阶引向唯一的 1×1 门洞。蹲行穿过低矮甬道后，进入收分叠涩顶的长廊，再下到三层迷宫。通路包含岔道、尽头和环路。最深处的墓室以石棺、壁柱和藏器坛标识。

石灰岩包面、叠涩长廊与石棺取意自胡夫金字塔。迷宫的压迫感与遭遇节奏取意自《夺命金字塔》。墓道连接和方块造型为本模组设计。[埃及旅游与文物部](https://egymonuments.gov.eg/monuments/the-great-pyramid/) · [20th Century Studios](https://www.20thcenturystudios.com/movies/the-pyramid)

### 缺片和守卫

旧流程在原生第四阶段生成完水草、海底生物、坟墓和其它装饰后，再对目标位置读值判断。任一表外方块会拒绝整片，造成笔直断面。新流程在第四阶段装饰之前预检基底，随后运行原生第四阶段，并在光照计算之前落下已通过校验的切片。测试用第四阶段会生成的海胆复现了旧的拒绝条件。检测到表外占用时仍保留该切片，并记录 block ID 与坐标。

迷宫仍有八只木乃伊与一位法老。第一只木乃伊放在入口长廊。每个点位检查玩家所在和生成点所在切片、房间高度、净空及身体占位，远处切片缺失时，已就绪的墓室仍可触发守卫。法老只在深处墓室出现一次。全部 25 片完成后，藏器坛可发放一件随机神器。

新版金字塔记录 `Tomb` 字段，旧迷宫沿用原记录的几何和守卫点位。新版外形应用于新区块。已保存的缺片保留原状，现有迷宫已生成的房间适用新的守卫触发规则。

## 火山

冷却火山、余火火山和三色火山湖均采用连续环壁。砂砾外坡向山脊抬升，山体终点按权重接回原地面。旧规则中纵切外坡的通道和背侧贯通洞已经移除。环壁岩基下探到坑底以下一格，填补原生洞穴在环壁下留下的空隙。岩浆仍由中心区块内的池床和围岸约束，原生液面和三色湖沿用各自的材料。

两处修复由房主或单机生成。使用已保存的旧火山区块时，原有地貌继续读取。
