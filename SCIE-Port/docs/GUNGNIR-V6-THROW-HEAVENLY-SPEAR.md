# 昆古尼尔 V6：技能名铭牌、投枪可靠性、天降巨枪

日期：2026-10-27。版本：0.40.0。目标运行时：SCNET `Net_x25.01.17`（Android 7723）。
本轮不改 ID 948、包 244/245 字段与序列化、伤害/半径/冷却/移速攻速、长按语义，只修三个用户可直接感知的问题。

## 1 技能名不可见 → 刻在图标内侧铭牌

**观察**：两个技能徽记正常显示，但「卢恩神佑」「永恒裁决」四个字看不到。

**原实现的风险点**：名称是徽记**下方**的独立 `LabelWidget`（`Visual` 高 `size + 18`，名称在 `y = size + 1`）。
该区域不属于任何布局参与块：`GungnirHudLayout.Place` 只按 72/88 的**按钮本体**做边缘收拢、快捷栏避让和原生命中避让，
名称条既不被计入避让，也不会随徽记一起上抬。因此只要设备 DPI/安全区、原生快捷栏宽度或右上角原生控件与名称条相交，
名称就会被抬出屏幕可视区或被原生控件压住；而图标本体依旧可见 —— 与「只有名字不见」的现象完全一致。

**本轮做法**：名称改为**刻在徽记内部**的铭牌带。

| 元素 | 尺寸/位置 | 说明 |
|---|---|---|
| `NamePlate` | `(size, 21)`，`y = size - 21` | 暗色玻璃底 `(8,10,14,186)` + 1 px 强调色描边，任何地形/天空背景下都有对比度 |
| `Caption` | `(size, 21)`，同一位置 | `FontScale 0.55`，就绪时铂金 `(247,232,195)`，冷却时灰 `(152,148,138)`，施法瞬间亮白 |
| `Energy` | `(size - 10, 3)`，`y = size - 25` | 上移到铭牌带之上，绝不会被铭牌覆盖 |
| `Cooldown` | `(size, size - 21)` | 居中在铭牌带之上的图标区，与数字不再互相压字 |

`GungnirHudLayout.NameBandHeight = 21f` 为唯一常量，离线测试断言 `0 < 21 < 72 × 0.4`，保证铭牌永远落在最小徽记内部；
`Visual` 恢复为严格 `size × size`，因此 `Place`、左手镜像、16 单位步长退让与既有 1280×720 / 1920×1080 / 1.25× / 1.5×
布局结果全部不变。命中区域仍是整块徽记（`HitTarget` + `Clickable`），点名字也会施法。

## 2 投掷若干次后无法投掷 → 自有蓄力时钟 + 飞行租约

**x25.01.17 反编译取证**（`Game.ComponentPlayer.Update`、`Game.ComponentInput.UpdateInputFromWidgets`）：

1. `PlayerInput.Aim` 由 `ViewWidget` 的 `Hold`（`Duration > 0.2s`）或 `Move`（`m_isViewHoldStarted`）写入，每帧重置。
2. 瞄准状态机门限为 `GameTime - m_lastActionTime > 1.4`（生存模式）。**每次 Completed 都会写 `m_lastActionTime`**，
   所以引擎自身的瞄准通路在每次投出后至少要 1.4 秒才会重新进入 `InProgress`。
3. 一旦某个行为在 `InProgress` 返回 `true`，引擎立刻 `Aim(Cancelled)`、清空 `m_aim` 并置 `m_isAimBlocked = true`；
   该锁只有「某一帧 Aim 为空」才会解除。

**旧实现的组合缺陷**：

- 投枪完全依赖 `OnAim(InProgress)` 记蓄力起点。飞枪期间 `OnAim` 返回 `true`（跳过蓄力），引擎随即置 `m_isAimBlocked`；
  玩家若一直按住或在 1.4 秒内再次按住，蓄力根本不开始，松手时 `ChargeStart < 0` 或被 `Now - ChargeStart < 0.25` 拒绝，
  投枪被静默吞掉。连续快速投掷时，这种吞掉会连续发生，表现为「投几次之后就不能投了」。
- 起手条件 `s.Phase != 0` 是硬门：只要相位因为任何原因（区块未加载、换槽、异常帧）停在 1/2，新的投掷全部被拒。

**本轮实现**：

- `Update`（`UpdateOrder = -5`，位于 `ComponentInput(-10)` 之后、`ComponentPlayer(0)` 之前）直接采样
  `ComponentInput.PlayerInput.Aim`，自建 `AimHeld / AimStart / AimDirection` 时钟：按下即起蓄力，松开即判定。
  完全绕开引擎 1.4 秒重新武装与 `m_isAimBlocked` 锁。
- `OnAim` 降级为空实现 `=> false`：不再消费任何瞄准状态，x25.01.17 不会在蓄力中途取消按住。
- `Launch()` 不做相位门：**飞行中/回程中再次松手会「召回」旧枪并立即重新投出**，输入永不丢失。
- 飞行租约看门狗：`Now - FlightStart > GungnirRules.ThrowLease (3.2s)` 强制 `Phase = 0` 并清空贯穿记录，
  即使出现任何异常帧也不会让下一次投掷被永久挡住。
- 蓄力窗口 `MinThrowCharge = 0.15f`（Aim 存在本身已要求 0.2 秒按住，合计约 0.35 秒按压），
  `CanCompleteThrow` 同步放宽到 0.15 秒，客户端上报与服务端计时判定一致。
- 网络路径不变：普通客户端仍在包 244 既有 `Phase` 传开始/完成/取消、在 `Blessing` 浮点槽上报本地时长；
  主机侧 `ThrowBegin` 不再要求相位为空，因此飞行中的再次投掷不会再被协议端吞掉。

## 3 永恒裁决 → 真正「从天而降的巨大长枪」

时间轴仍以 0 秒起手、**1.4 秒结算伤害**、9 秒恢复为骨架（`GungnirSkyRules` 未改动 `Lifetime / ImpactTime / SkyBlend / ImpactFlash`）。

| 阶段 | 时间 | 表现 |
|---|---|---|
| 裂穹 | 0 → 0.42s | 目标上方出现竖直裂口：白芯光柱 + 逐层张开的金色「裂颌」+ 向封印灌注的光幕 |
| 显形 | 0 → 0.95s | 4.6 倍巨枪在 40 格高空凝聚，缩放 0.5→1.0，天空符文光带汇聚入枪身；地面三层法阵自内向外点亮 |
| 俯冲 | 0.95 → 1.40s | 三次缓入下坠（40 → 8.72 格原点），枪尖朝下，附 0/1/2 层速度残影、跨 40 格高的长尾迹、枪尖前方的压缩气环 |
| 落地 | 1.40s | 唯一主爆闪（9.5 格十字 + 24 段冲击环）、三层错峰冲击波、沿枪身上升的余烬与向外漂移的符文碎片 |
| 余威 | 1.40 → 3.4s | 巨枪深插地面（枪尖入土 1.4 格，枪尾高出地面约 17 格），0.6 秒内回落并轻微震颤 |
| 消散 | 3.4 → 7.8s | 枪体整体淡出，天空与地面法阵按既有 7–9 秒曲线恢复 |

纯函数 `GungnirSkyRules.SpearHeight / SpearScaleFactor / SpearAlpha / SpearFalling` 承载全部时间轴，
场景层只负责绘制；离线测试断言「可见期内高度永不为负、俯冲单调不回升、1.4 秒精确落在 `SpearImpactHeight`、
埋地后仍高出地面 8 格以上、可见窗口与俯冲窗口闭合」。低画质保留巨枪与核心爆闪，去掉残影与部分余烬。
