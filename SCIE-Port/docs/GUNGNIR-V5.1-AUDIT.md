# 昆古尼尔 V5.1 / V5.1b（SCIE-Port 0.34.0）审查记录

日期：2026-10-27。目标：SCNET `Net_x25.01.17`，Android 2.4 联机版。本页中的“已确认”仅指固定 Windows 目标程序集、源码、离线测试、Release 构建与包结构；没有把桌面模拟写成 Android 真机结论。

## HUD 定位与输入边界

- 目标 `GameWidget.xml` 的 `LookPad`/`MovePad` 为 160×160 逻辑单位，并由 `SettingsManager.LeftHandedLayout` 镜像；目标程序集确认 `ComponentGui.LookWidget`、`ShortInventoryWidget`、`Widget.GlobalBounds` 与 `ScreenToWidget` 可用。
- 每次实际控件矩形、容器尺寸或左右手布局改变时重新布局。屏幕矩形先由 `GlobalBounds` 转成 `ControlsContainerWidget` 本地坐标，再把 72×72 神佑放到 Look 左侧、88×88 裁决放到神佑右上。布局器还避让快捷栏和实际可命中的 Button/Touch/MoveRose/InventorySlot；找不到有效 Look 时才用可验证的右下相对回退。
- 只有图标等大的 `ClickableWidget` 命中；名称位于视觉容器中但不参与命中。根容器、文字、边框、能量条均不命中，因此不新增全屏输入层，也不改变原生查看、攻击、跳跃和长按投枪路径。
- 仅本地有效玩家装备 ID 948 时显示；换装、死亡/玩家移除、世界卸载分别由装备检查、项目有效性和 `GungnirHud.Clear()` 隐藏/清理。
- 离线布局日志：1280×720 → 神佑 `(962,609.3,72,72)`、裁决 `(1022,513.3,88,88)`；1920×1080 → `(1602,969.3,72,72)` / `(1662,873.3,88,88)`；1.25× UI 的 1024×576 逻辑空间 → `(706,422,72,72)` / `(766,326,88,88)`；1.5× UI 的 1280×720 逻辑空间与首组一致。全部断言 Look/快捷栏不重叠，左手镜像通过。

## 视觉实现

- 两枚 512×256 透明图集徽记由 `New-GungnirAssets.py` 原创生成：神佑为青金符文盾，大招为白金神枪及更强外环。按钮具有金属环、冷却灰暗/数字、就绪呼吸、按压高亮、神佑剩余秒数和 3 px 能量条。
- 去程：1.10 倍可见枪体、白金能量脊、逐段枪身符文、细白亮芯、窄金色内辉和按画质缩放的外辉，形成直线贯穿语言。
- 回程：1.14 倍暖金枪体，轨迹更长更粗；始终保留暖金亮芯、至少一条螺旋线、一个符文和一个轴向环，高画质增至双螺旋/三符文/双环。去程与回程不再共用同一条拖尾。
- 命中使用 0.24 秒小型金白闪光和冲击环；Phase 1→2 折返使用 0.38 秒暖金符文环与十字闪光。固定 24 槽覆盖式提示池，不在每帧创建集合对象。
- 高/中/低画质的主环段数为 64/40/24，拖尾层数 3/2/1，回程螺旋段数 9/7/5，动态回程符文 3/2/1，回程环 2/1/1。低画质仍保留枪体、去程亮芯、回程螺旋/符文/环和折返提示。
