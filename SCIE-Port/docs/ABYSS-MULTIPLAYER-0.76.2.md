# 阿比斯普通玩家使用修复 / 0.76.2

2026-11-03，基线main `a53d5f2` / 0.76.1。用户报告联机显示“需要主机确认”，要求普通玩家同样可以使用。

## 查到的问题

`WorldCutRuntime.EndCharge`会无条件显示「蓄力断界斩 · 主机确认中」，单人也会出现；收到成功事件后只清除等待标志，没有立即清除文字。它实际是请求/回执过程，没有房主点击批准的入口。折跃、破碎和虚夜也使用请求主机或主机允许的措辞，容易被理解成人工审批。

另有实际功能限制：`SubsystemAbyssReaper.Strike`在虚空普攻中直接排除Client及Server上的非主玩家，注释仍为V0.1“不接入远端输入”。客户端原生攻击射线已被本Mod接管，因此普通玩家会有挥动而没有这条攻击的伤害结算。死亡形态普攻、重击、空间技能、领域、星门及军势已有自动处理的联机请求路径，没有单独的房主批准开关。

## 修改后行为

- 普通玩家、房主与单人均在输入命中点提交既有252包Kind0/Action5；两种权柄共用身份/连接Token/世界/序号验证，自动处理，无需房主额外操作。
- 主机依当前权柄选择攻击逻辑。虚空普攻调用原扇形/点选目标逻辑，4.5格、22/22/34基础伤害、墙体/移动方块/领地/友军/默认玩家保护和扫描预算保持；死亡赋能及契约逻辑保持。客户端没有可信伤害或连击段数输入，不能本地重复造伤害。
- 虚空连击的请求间隔按48%命中点计算相邻两段动作之间的时间，包含现有攻速倍率；避免用第三段完整时长阻挡下一轮第一击。死亡形态原间隔保持。
- 既有Kind5演出现在也对应虚空普攻，向客户端复制主机选定的连击段数和方向。本地玩家沿用原输入动画，远端玩家使用既有挥动场景。
- 重击/空间技能待回执文案精简为「释放中」；重击收到本人成功事件立即清除待回执文字。领域拒绝仍提示冷却或「暂时无法释放」，不再描述为主机审批。

图谱解放真名、持物/存活/清醒、动作互斥、技能冷却、军势容量和唯一性、地形及领地条件仍按双方同一规则验证；这些不是房主专属权限。未解放真名仍需本人在图谱中解放。断网/未同步/超时会有必要反馈；没有把断网客户端当成主机执行共享世界伤害或召唤。
