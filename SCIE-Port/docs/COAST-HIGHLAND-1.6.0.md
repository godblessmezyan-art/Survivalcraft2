# 海岸与高地奇景 1.6.0

跨区块奇景增至 23 种，小型地标增至 18 种。

| 跨区块奇景 | 选址和形态 |
| --- | --- |
| 寒崖峡湾 | 较凉的岸线，外侧有深水并可连接海面，内侧有高地。蜿蜒入海水道两旁是高低错落的花岗岩崖，靠近尽头有浅滩。参照[挪威西部峡湾](https://whc.unesco.org/en/list/1195)。 |
| 断云桌山 | 暖湿内陆，中心距海平面至少 12 格。砂岩平顶高出中心天然地面约 24–28 格，陡壁有彩岩带，一侧保留一段斜向上山的坡面。参照[卡奈马国家公园](https://whc.unesco.org/en/list/701/)。 |
| 浅海礁道 | 水深适中的近海台地，三条浅色水下礁脊之间留两条水道，中间礁脊另有一个横向缺口。 |
| 雪脊冰阶 | 寒冷且起伏不过高的内陆高地，交错露出蓝冰阶面和花岗岩肩，中心有一条随山势弯折的缓坡。 |

| 小型地标 | 选址和形态 |
| --- | --- |
| 潮缘礁池 | 海平面以上 1–5 格的温暖近岸岩地。碎石池底和石灰岩围岸圈出两座浅池，完整验证后一次写入。 |
| 湿地草岛 | 温暖湿润的近岸内侧或内陆浅水。两片低草岛露出水面，保留周围水面与岛间空隙。 |
| 雪线风脊 | 高于海平面至少 12 格、达到结冰阈值的高地。低矮风脊中央隆起，两头渐低，花岗岩脊顶覆雪。 |
| 红岩窄缝 | 干暖内陆的沙或砂岩地。碎石沟从两头渐深，短窄岩壁在中段错位。 |

符合条件的新旧奇景共用候选池。浅海礁道可与环礁蓝洞和黑沙柱岩海岸竞争，雪脊冰阶可与冰川长脊、蓝冰洞和冰蚀围谷竞争。每个 192×192 格区域最多一处跨区块奇景。同类小型地标在周围两圈区块内避让，每个区块最多生成一处。新增海上奇景避让水幕沉殿的选址范围。

大陆、岛屿和 Better 的新生成区块使用新版规则，已保存区块照常加载。跨过已有区块边界时，大奇景可能只生成未保存的一侧。固定种子样本见 [测试结果](TEST-RESULTS.md)。
