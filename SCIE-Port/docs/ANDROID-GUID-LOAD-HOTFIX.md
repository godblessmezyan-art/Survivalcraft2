# Android世界加载失败：GUID解析 / 0.75.1

用户在2026-11-01反馈0.75.0无法进入世界。截图/日志显示图谱子系统Load抛出`MissingMethodException: bool System.Guid.TryParse(string,System.Guid&)`；Mod MVID `867e656d-6479-49fa-bb44-ae2fb7ed7d60`与本地0.75.0包一致。Windows有该方法，用户的Android运行时没有；即使TrueNames为空，也可能在JIT解析该调用时失败。旧Windows构建/隔离测试无法发现手机缺少此接口。

0.75.1增加只依赖`new Guid(string)`的兼容解析器，将图谱1处和星门4处读取全部转入该解析器。格式、溢出或参数错误返回false并清空out值；有效GUID的N/D/B/P/X形式与前后空白保留原解析规则。图谱继续跳过无效/空玩家标识，星门继续严格拒绝非法记录、保留空Target表示未连接。存档字段、GUID文本、真名掩码、星门链接与既有协议保持，不重置解锁，不迁移世界，不改变召唤概率或神器行为。

Release测试增加整DLL的实际IL调用检查，禁止任何直接`System.Guid.Parse`/`TryParse`/`ParseExact`/`TryParseExact`引用，并检查图谱及四个星门入口均使用兼容解析器。实际目标子系统Load分别验证无TrueNames的旧世界、已有解锁及混合非法/有效玩家记录；既有星门保存/加载、XML安全与完整回归继续运行。阿比斯冻结源码保护仅规范化固定解析器调用目标，再匹配原冻结SHA，没有更新基线或修改星门算法。具体命令、检查数量和包指纹见[测试记录](TEST-RESULTS.md)。

安装时保留并备份原世界，将NetMods内旧「荒野探险家」包替换为0.75.1，完整退出游戏后重新启动；同房各端统一更新。先用可丢弃世界/备份验证新建、旧世界加载和解锁进度，有星门的世界再核对星门恢复。手机实际结果仍待用户复测。

日志同时包含`Error enumerating files/directories: Access ... is denied`，这是另一个目录访问错误；当前加载堆栈明确中断于图谱缺失接口。0.75.1只处理已定位的运行时依赖，若替换后还出现目录错误或新的加载异常，应依据新的完整堆栈继续定位，不能提前将存储权限问题标为已解决。
