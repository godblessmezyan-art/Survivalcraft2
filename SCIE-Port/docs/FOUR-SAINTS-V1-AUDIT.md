# 四圣兽神装 V1 审查与验收

## 目标 ABI 与生命单位

- 固定目标为 SCNET `Net_x25.01.17`；Windows 取证程序集 `Survivalcraft.exe` 版本 `2.4.0.0`，目标框架 net472。
- 实际 `ComponentHealth.Health` 使用浮点归一值，原生 `Heal` 上限为 `1.0`；原生 10 格生命条对应显示生命 10 点，因此本模块统一使用 **0.1 引擎值 = 1 显示生命点**。
- 目标程序集没有“最大生命值”属性，`ValueBarWidget.Value` 也会夹到 0～1。青龙采用世界作用域的有效上限 `1.5`，服务器直接同步生命值，本地主玩家生命条切成 15 格并显示 `Health / 1.5`；卸下时将超过 1.0 的部分收回并恢复原生命条格数。该兼容层不会每帧改写生命值，但与另一个同时扩展生命上限/HUD 的 Mod 的组合仍待真机验证。

## 装备注册

四件均复用原生衣物方块 ID 203，不新增方块 ID。新增衣物数据号：

| 衣物数据号 | 名称 | 槽位 | ArmorProtection | Sturdiness |
|---:|---|---|---:|---:|
| 200 | 青龙冠 | Head | 1.0 | 320 |
| 201 | 玄武铠 | Torso | 1.0 | 480 |
| 202 | 白虎胫甲 | Legs | 1.0 | 360 |
| 203 | 朱雀靴 | Feet | 1.0 | 340 |

`ArmorProtection=1.0` 进入原生随机护甲槽、磨损和吸收计算，不等同于额外全伤害无敌。资源由 `scripts/New-FourSaintsAssets.ps1` 以项目原创几何纹样可复现生成，不引入第三方美术。

## 权威效果

- 青龙：权威游戏时间每 5 秒恢复 0.1，满血不恢复；重新穿戴重新等待完整 5 秒。跌落原因字符串在 `OnCreatureInjure`、死亡判定前拦截。
- 玄武：目标版本溺水原因在同一伤害入口拦截；带攻击者的最终生命伤害在原生护甲和韧性之后减 0.3，并夹到零，只重放一次伤害事件。V1.1 另精确拦截 `ComponentVitalStats.UpdateTemperature()` 的两个直接严寒原因：`LanguageControl.Get(ComponentVitalStats.fName, 25)`（体温≤0 时 1.0 伤害）和索引 `26`（体温<3 时每10秒 0.05 伤害）。两条路径都进入 `ComponentHealth.Injure`，没有绕过现有权威 Hook；体温、湿度、环境温度和保温计算均不修改。过热使用索引 `35`，不会被拦截。
- 白虎：衣物原生 `MovementSpeedFactor=1.2`；跳跃按 `v2²=v1²+2g·1`、目标重力 `g=10` 换算；普通/觉醒攻击频率分别为基础 1.2/2.0，觉醒直接战斗生命伤害乘 1.5 一次。与妙尔尼尔 1.1 攻频使用乘法组合，与昆古尼尔自己的攻击频率也统一相乘。
- 朱雀：火焰、岩浆原因在伤害前拦截，穿戴时调用原生 `Extinguish()` 并清除 `TouchesFire`。非强制伤害若会降到 0.1 或以下，则阻止该事件、恢复到 1.0（受当前 1.0/1.5 有效上限约束），开始 1 秒无敌与移动/跳跃/攻击锁。无冷却；同一窗口不会递归触发。世界销毁等非伤害流程不被拦截。

白虎请求和定时状态使用新增包 245。服务端根据 `From.PlayerData.ComponentPlayer` 校验实体、装备、生命、锁定、冷却和序号；客户端只提交请求，不提交持续时间。服务器广播剩余时间快照，客户端拒绝旧 revision。换下白虎立即结束觉醒，60 秒冷却不清除。

## HUD

白虎按钮为 76 逻辑单位透明银白虎纹/暗金双环，只有图标区域接收触摸。它从真实 `ComponentGui.LookWidget` 与 `ShortInventoryWidget` 的全局矩形转换到 `ControlsContainerWidget` 坐标，再扫描原生按钮、触摸面、移动盘与物品槽避让；分辨率或 Look 布局改变时重新布局。显示 5 秒持续和 60 秒冷却数字、就绪呼吸光与按压高亮。

离线模拟覆盖 1280×720、1920×1080 和 1.35 UI 缩放，Look/快捷栏碰撞为 false。攻击/跳跃等实际控件矩形依靠运行时扫描，Android 多点触控和安全区域仍必须真机确认。

## 离线结果

- `scripts/Test-Environment.ps1`：目标程序集哈希/ABI、原生包 0～38 与保留包 240～245检查通过。
- `SCIEPort.FourSaints.Tests`：玄武边界、白虎普通/觉醒攻频、一次伤害倍率、妙尔尼尔组合、跳跃增高公式和三组 HUD 布局通过。
- V1.1 回归将四圣兽套件扩为 25 条断言：增加青龙回血/上限、白虎 5/60 秒、朱雀 1 秒窗口，以及玄武溺水/两种严寒精确命中、卸装失效和过热、流感、跌落不命中的分类测试。构建脚本另锁定运行时代码必须引用目标索引 25/26，且禁止引用过热索引 35 或 `ComponentFlu.fName`。
- 全量 `Build-NetMod.ps1`：全部既有测试、17 XDB、net472 Release（0 warning / 0 error）和包条目校验通过。
- 最终包数据在 `docs/TEST-RESULTS.md` 记录。以上均为 Windows 离线/程序集验证，不是 Android 或联机实测。
- V1.1 最终包为 3,482,940 bytes / 107 entries，SHA-256 `D1E1F8E6393740C9DE46F72172650A89CDF9AF74054C8A28BD90EB181325FED3`，版本 `0.38.1`。
