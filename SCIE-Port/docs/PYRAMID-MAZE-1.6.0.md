# 日阶迷宫 · 1.6.0

阶梯金字塔在暖干内陆选址，占用原有 80×80 格生成范围。砂岩围合外壁、屋顶和地下底板。北面石阶顺着地势通往唯一的 1×1 正门，玩家用原生蹲行穿过门洞，进门即可站起来。

迷宫由三层、共 192 个相通小间组成。走廊在转角分岔，一部分形成环路，另一部分通向尽头。两段石阶把三层串起来，可以原路返回。各层的路线由世界种子决定，藏器室可直接探索。对 25 个布局种子做方格寻路，正门到藏器室的最短路线为 632–822 步。

八个木乃伊点位按 3、3、2 分布在三层，唯一的法老在最深处守着藏器室。房主或单机世界在玩家靠近相应区域时生成守卫。每个点位只生效一次，记录随世界保存。藏器室保留原有随机神器，由原生悬浮陈列器发放一次。

## 区块和存档

新版布局用于新区块。新版神殿以 `MazeSeed` 和 `ApproachFloor` 保存走廊布局与门前石阶高度。缺少 `MazeSeed` 的神殿按旧版布局和封印进度继续读取。旧世界可以在未生成区域遇到新版神殿。

生成线程每次只校验和写入当前的 16×16×51 格切片。新版地基和封闭底板会占用生成范围内的原生地形，允许替换同一新区块内原版第四阶段产生的坟墓及石堆装饰。已保存的占地区块使候选作废。检测到不在允许表内的占用时，整个切片保留原值。全部 25 个切片完成后才生成守卫与奖品。地形和实体由单机或房主生成，客户端接收原生同步。

日阶机关 1023 在新区块用于藏器坛、石灯和浮雕，即 DATA 10–12。旧址沿用 DATA 0–9 的封印、提示与石门，以及原机关包 234。

## 实机复测点

用默认生物群系尺度新建大陆世界，种子输入 `SunPyramid`。固定 Windows 目标的正门在 **X=213、Y=75、Z=908**。从北坡走上石阶，蹲下过门。Android 7723 首测关注蹲行进出、双向上下石阶和战斗。联机用相同版本分别观察首次进屋、守卫击败及重进。
