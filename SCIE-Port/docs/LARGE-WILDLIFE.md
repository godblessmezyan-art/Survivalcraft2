# 苔背巨龟和云翼巨鳐

两种生物通过原生野外刷新生成。单机或房主负责生成、移动和战斗，普通客户端使用原生实体同步。每种每次生成一只。生成点周围 42 格内已有同种生物时，该点暂停刷新。

## 苔背巨龟

巨龟出现在温湿低地的宽河岸和湿地。选址检查龟身下方的完整占地、岸边可达的一格深浅水，以及通往浅水的缓坡。白天在岸边低速活动和晒背，夜间走到浅水，天亮后返回岸上。行走时用原生一步高度的平滑抬升，足底预检会挡住断崖。

第一次受击会缩头护壳，进入短暂的减伤窗口。同一玩家短时间内再次攻击时，巨龟会转向、伸头顶开身前的攻击者，再尝试撤到浅水。顶撞走原生护甲和击退，并检查距离、角度和遮挡。新增 230 号主机表现包同步缩头和顶撞。

## 云翼巨鳐

巨鳐在开阔高地上空刷新，沿附近坡脊盘旋。巡航时传入水平和垂直原生飞行指令，朝向跟随航线。局部地形预检避免它飞入未加载的区块。周期性寻找双翼有净空的宽草甸，减速下降，短暂停留后再起飞。受惊或受攻击时会离开落点。低空飞过时投射随身体转动的宽影，受原生「物体阴影」设置控制。

「自然与生物」的苔背巨龟生成器和云翼巨鳐生成器共用物品 ID 891 的 DATA0 和 DATA1。单机或房主可在净空足够的地面顶面使用它们。巨鳐生成器从目标地面抬高 7 格放入空中。

两套原创刚体骨骼模型和 128×32 图集使用 python SCIE-Port/scripts/New-LargeWildlifeAssets.py 生成。同尺度预览使用实际导出的 DAE，参照玩家碰撞盒与沙蝎静止模型。Windows 固定目标通过原生模型、数据库、缓坡及宽翼净空离线检查。实际自然刷新密度、上岸观感、滑翔和降落动作、Android 7723 与真实联机待实测。
