刻尔柏洛斯模板与契约局部配置一起改为444，战马局部配置改为44。绑定/恢复/现身时应用，保留原有生命百分比；旧半血战马由18.5/37变为22/44，旧半血三头犬由150/300变为222/444。旧次位面生命元数据也按新上限显示。原生野生狼/马、普通转化生物基准、移动/伤害/冷却及唯一性规则保持。

夺魂赋刃首击仍将目标压到最多1点生命，第二击契约成功后改为**1点生命**，取消自动回满。按接管后的实际AttackResilience换算原生Health比例：`1 / max(1, AttackResilience)`。原生`Health=1`表示100%满血，因此不能直接赋值1。本版移除换算中一百万的上限，避免大型生命基准目标换算后仍高于1点。换算前继续校验有限值，非法值沿用100的兜底；最大生命不足1的目标以满血为上限。

生命由主机写入原生健康包，并立即补发友军生命行；客户端只显示主机结果。反馈改为“灵魂契约成立 · 保留1点生命”。已有友军不追溯降血。原生后续回血和死亡蔓延回满军势能力保持；这是转化瞬间的血量，不是永久锁血。

## 断界斩：已定位的缺陷与仍待确认的故障

用户报告虚空形态、未使用其他技能、平视空旷处重击仍提示“当前无法释放断界斩”。仅凭原提示无法确认实际根因：旧代码将Unavailable、Invalid及部分执行异常合并到该句，蓄力启动失败也可能走同一提示；重击StartCast的异常捕获还没有写出日志。用户的平视条件不能用近垂直视角缺陷解释，不声称实际故障已复现或彻底修复。

本版保留原角色和技能互斥校验，细分角色未就绪、技能占用、赋刃禁用、蓄力丢失、无效朝向、请求校验和执行异常。失败释放清理本地残留蓄力并发取消，服务器蓄力建立失败由原静默返回改为明确拒绝反馈，保留原序列/连接令牌/到期/重放验证。两处执行异常记录完整异常和堆栈，便于用户实测定位。

另有确定的代码边界问题：将视线投影到水平面后长度平方不足0.01就拒绝，近垂直抬头/低头会触发。本版此时使用主机已同步的身体水平朝向；仍不接受客户端自报方向或伤害。此项是代码修正，真实画面待验证，不能替代用户平视故障的确认。

重击仍需主机累计原0.65秒蓄力（按攻速缩放），独立于旧10秒技能按钮冷却，不增加伤害或取消权限校验。247字节布局不变，在既有Reason字段追加10–13的显示原因，旧0–9值不变。249/250/252及契约v1/v2保存格式保持；各方统一0.65.3以获得一致属性和提示。
