# 全知之眼 / The All-Seeing Eye V0.1

主线工程版本 0.42.0，分支 `main`（功能来源：`port/scnet-x25.01.17` 的 `896469b`，
原开发构建 0.14.0）。这是原“开发者工具”的正式
神器设计：创造栏“神器”分类内获取；无耐久、不能放置、无攻击伤害，点击使用
打开“万象解析”。环境、方块为正式页；生物、诊断显示禁用的预留入口。

## 模型与视觉

完全原创的深蓝悬浮六面晶体，正面青蓝晶面瞳孔与暖白高光；两道交错黄铜星环，
星环表面青/白符号刻饰；短柄、四道铜箍与柄尾配重。使用实体几何与不透明调色板
表达星辉，不使用发光着色器和模型透明混合。Y_UP，米制，变换烘焙到顶点，
单 identity 场景节点，25 meshes / 784 triangles。正面为 -Z，CSV 指定正面稍侧的
物品栏视角；第一人称缩放 0.7、第三人称 0.6，最终比例与方向待 Android 验收。

- 模型：`src/SCIEPort/Assets/Models/OmniscientEye.dae`
- 贴图：`src/SCIEPort/Assets/Textures/OmniscientEye.png`，128×16、RGBA、Alpha=255。
- 生成：`python SCIE-Port/scripts/New-OmniscientEyeAssets.py`（仅 Python 标准库）。
- 可选软件预览：`python SCIE-Port/scripts/Preview-OmniscientEye.py`（需 Pillow）。
- 权属/哈希：`THIRD-PARTY-NOTICES.md`。没有复用新生代模组资产。

## 数据与交互

HUD 默认关闭，可从主面板反复开启/关闭，切换手持物品后保持。
每 0.2 秒读 `ComponentBody.Position`，用 `Terrain.ToCell/ToChunk` 转为高度与区块坐标，
包括负坐标；每 1 秒从当前已就绪区块读取 `Terrain.GetTemperature/GetHumidity` 和
区块状态。温湿度是地图柱基础气候 0–15 级，不是季节修正气候、摄氏度、百分比、
玩家体温或含衣物/篝火影响的感受温度。高度是世界 Y，不是海拔换算。

方块页只在点击“主动扫描”时从本地相机朝向执行原生 Digging 射线，最大结果距离
8 格，不命中或未加载时显示明确提示。读取名称、坐标、Contents ID、DATA、光照
等级、类型名、距离，不自动不断扫描，不分配/请求新地形区块。

HUD 深蓝半透明底板、古铜边框、青蓝文字，无命中测试。测量原生左右控制组、
移动/视角区、快捷栏、血条、等级标签，优先上中部，依次尝试 Y=8/64/128，保留
8 单位安全间距；空间不足时隐藏而不遮挡。打开原生模态面板/对话框时隐藏。
HUD 宽 248–340、高 118，字号不随宽度缩小；主面板 520×344，根据当前玩家
viewport 缩放，通常按钮高 44。极小 viewport/高 UI 缩放下按钮可达性待真机测试。

## 注册、线程与生命周期审查

- 新增 Block ID **949**：目标原版 260 常量与 main 既有 903–948、995–1000 均未占用；
  构建扫描全部本工程常量拒绝重复。第三方模组不具有全局 ID 注册表，任意并装仍待验证。
- 标准 CSV 与 `OmniscientEye.xdb` 注册，不替换原生类，不新增网络包，不修改存档格式。
- `SCIEPortLoader.__ModInitialize` 注册一次 `GuiUpdate`，未逐帧注册 Hook 或事件。
- UI 由当前 Project 的 `SubsystemOmniscientEye` 持有；字典每个本地 ComponentGui
  一个 EyeView、一个 HUD。OnUse 只设打开请求，GuiUpdate 统一刷新数据与界面。
  没有后台 Task、Timer 或线程访问游戏状态。
- 只有拥有 GameWidget 的玩家创建 UI；远程玩家/无本地视口不会创建。状态不使用
  静态玩家/世界引用。本地玩家移除或重生更换组件时旧视图退役。
- 退出世界调用 Subsystem.Dispose：移除 HUD、关闭 Dialog、释放 Dialog 对玩家的引用、
  清空状态字典。原生 Dialog 关闭动画由 DialogsManager 管理，动画不保留 EyeView 引用。
- UI 异常按单个玩家关闭视图并记录一条日志；不关闭其它模组/玩家的 GuiUpdate。
- 数据均只读；不调用地形/实体写 API，也不消耗工具。联机只读不代表已经通过联机实测。
- Builder Assistant 仅读取其 GuiUpdate 参考实现；未引用或改动其源码/资源。

## Android 7723 真机验收清单（全部待验证）

使用新建可丢弃世界，保留旧存档备份；记录 APK 来源/精确版本与可取得的程序集指纹。

1. 冷启动 0.42.0，确认无加载异常，创造栏“神器”内仅一个全知之眼条目。
2. 检查图标的星环、瞳孔、晶体、柄，日光/阴影/室内、第一/第三人称均可见；
   无透明漏面、翻转、黑块、过大遮屏，朝向及握柄自然。
3. 触屏点用工具可打开主面板；环境/方块页可切换；预留入口不能点击。
   点击关闭、Android 返回、重复开关 30 次不叠加窗口或 HUD。
4. 开启 HUD，换手持物品后仍显示；关闭后立即消失。移动时坐标约 5Hz、气候约 1Hz；
   跨负坐标/区块边界时正确，温湿度无 °C/%，高度与实际世界 Y 相符。
5. 对比原生地形数据验证温湿度；未就绪区块显示提示，不显示伪造零值。
6. 扫描石头、带 DATA 的方块、空气、8 格外方块：按钮触发、结果/超距提示正确；
   转头不点击时结果保持；无方块变化、掉落、损耗或实体变化。
7. 854×480/1280×720/1920×1080 和宽屏；UI 1×/1.25×/1.5×；左右手布局：
   HUD 不遮移动、视角、快捷栏及侧边按钮，字号可读；模态面板打开时隐藏；
   安全空间不足时隐藏可接受，主面板仍可看数据并关闭 HUD。
8. 两个本地玩家分别启用/关闭，状态和数据不串；移除玩家、死亡重生无旧引用异常。
9. 开着 HUD/对话框退出世界并进另一个世界，旧 HUD 不残留，新世界默认关闭；
   重复 10 次，无重复 Widget、日志刷屏或明显内存持续增长。
10. 单机通过后分别测试房主和普通客户端：数据对应本地玩家；不产生修改世界的
    网络操作；检查频道/版本一致性和任意外部模组的 949 冲突。
11. 中低端 Android 连续启用 10 分钟，对比关闭时帧率与内存，记录机型/分辨率/版本。

结果表分别填写 Windows 游戏运行、Android 模型、触控、小屏布局、生命周期、多人、
性能；编译和软件预览的通过不能填入这些实机栏。
