# 地表与奇景 1.4.0

小型地标增加到 14 种，跨区块奇景增加到 15 种。大陆、岛屿和 Better 模式的新生成区块使用新规则。

| 小型地标 | 选址与形态 |
| --- | --- |
| 碎石坡扇 | 内陆岩坡，上缘距海平面至少 8 格，6 格水平距离下落 3–10 格。碎石带向坡脚逐步变宽，夹杂露出的岩块。 |
| 草覆岩丘 | 暖湿内陆草地，中心高于海平面至少 3 格。三座高一至两格的草顶小丘之间保留原有草地。 |
| 冻土石纹 | 达到结冰阈值的内陆高地。碎石接缝与薄雪铺成错开的斑块，高差或植被超限的地表列跳过，完整度不足时放弃候选。 |

| 跨区块奇景 | 选址与形态 |
| --- | --- |
| 花岗岩穹丘 | 有湿度且起伏较缓的内陆，从部分原柱状节理台地和钙华彩池候选中分出。三座不同高宽的圆丘由浅岩缝和碎石带隔开。 |
| 冲蚀沟壑 | 暖干且略高于海平面的内陆，从部分原干峡谷和七彩丘陵候选中分出。支沟斜切彩岩山脊，与弯曲的碎石主沟汇合。 |
| 冰蚀围谷 | 寒冷内陆，中心至少高于海平面 18 格，从部分原蓝冰洞候选中分出。三面是高起的岩壁，谷底露出蓝冰，开敞的一侧用缓坡接回周围地面。 |

小型地标按种子抽取不同的首选与备选。相对区块坐标在两圈内的候选（含斜向）共享同一排序，较高优先级保留同类候选。规则只使用种子与坐标，反向探索也会得到相同候选。选址检查后每区块最多生成一处，实际出现率低于候选率。

跨区块奇景复用 192×192 区域内的已有选址中心与占用范围。新奇景跳过原生水、冰和岩浆覆盖的地表列。小型地标先规划再提交，最多规划 640 格。跨区块奇景每列先校验，检查范围至多 58 格。保存过的区块保持原状，大奇景与旧存档交界可能只生成未保存部分。

复用原生石材、碎石、草方块、雪及既有彩岩 1009 与蓝冰 1011。Android 7723 与真实联机待验证。
