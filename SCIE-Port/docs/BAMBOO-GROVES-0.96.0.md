# 竹林与竹笋 0.96.0

- **竹子 932**沿用旧方块身份。下段是细长竹竿，顶部有茂密枝叶。保留竹根并采去上段后，竹子会在合适环境下长回原高。砍去支撑时，上段逐节掉落可收集的竹竿。
- **竹笋 1001**可从竹林采得，可直接食用，也可移栽在草方块、泥土、耕地或沙地顶面。竹笋经历三个可区分的阶段后转为竹根，继续长成 5–8 格高的成竹。
- **竹材 933**沿用实心建筑方块。新增原版配方，四段竹竿摆成 2×2 合成一块竹材。

植物跟随原版区块第四阶段生成。符合暖湿低地气候的区块有 24% 概率尝试生成一片竹林。竹林占用半径三格，最多 8 株成竹与 2 株竹笋，每株 5–8 格高。候选位置根据区块种子确定，优先选择有自然土、起伏较缓且上方有净空的位置。生成仅写入当前新区块的空格。已探索过的区块可人工种植。

旧竹根 DATA bit 0 和旧上段 DATA 0 继续有效。既有竹根保持最多八段，新竹根将高度保存在 bit 1–3。竹梢模型根据上方紧邻方块实时确定，旧竹子在区块重绘后也能看到竹节和支叶。竹笋采下或再种时用初始苗龄。原生地形和拾取物同步由主机负责。各联机端使用相同版本。
