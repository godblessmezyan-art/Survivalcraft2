# ATV v0.2 稳定性审计

目标：Survivalcraft NET 2.4 `Net_x25.01.17`，最终平台 Android 7723。兼容性状态只使用
“已确认 / 待验证 / 不支持”。程序集哈希沿用 `API-DIFF.md` 中固定目标的记录。

## 根因与证据等级

| 问题 | 证据等级 | 结论 |
|---|---|---|
| 平地速度建立过慢 | 已确认 | v0.1 自定义加速后，真实 `ComponentBody.Update` 又以 `6*dt` 将接地速度拉向 `StandingOnVelocity`；同时自定义控制器还做滑行和横向抓地，形成双重阻力 |
| 离开地面立即明显减速 | 已确认 | v0.1 在 `StandingOnValue` 与 `StandingOnBody` 都为空时调用 `ApplyCoastingGrip`，按 `7*dt` 将全部水平速度拉向零 |
| 横向抓地依赖帧率 | 已确认 | v0.1 每帧固定使用 `Vector3.Lerp(..., 0.35)`，没有乘 `dt` |
| 物品模型重复面 | 已确认 | `AtvBlock` 对每个 part 同时追加正常和反向 winding；模型是闭合 cuboid，不需要第二套共面三角形 |
| 模型结构不足 | 已确认 | v0.1 只有一个 8 顶点 cube geometry，被车体和四个轮节点共享；没有独立座椅、车把或车头结构，轮胎也是非独立 cuboid 实例 |
| 材质没有部件区分 | 已确认 | v0.1 `ATV.png` 是 1×1 白色，所有 UV 只能取得同一像素，世界模型再统一乘绿色 DiffuseColor |
| 0.8.2 Android 世界模型空白 | 已确认 | 用户实测物品栏图标可见但生成实体无模型。目标 `ModLoader.GetMaxInstancesCount()` 固定返回 7；目标 `Engine.Media.ModelData.Load` 将 0.8.2 DAE 导入为 10 bones/9 meshes。物品路径将网格烘焙到 `BlockMesh`，世界路径通过实例模型着色器提交全部骨骼变换，因此只有世界路径越过预算 |
| PNG 格式或透明度导致混乱 | 不支持 | v0.1 文件本身是可解码的不透明 PNG；没有证据支持“格式不受支持”。v0.2 仍增加尺寸、颜色数和 Alpha 守卫防止回归 |

## v0.2 修改

- 保持 `AtvBlock.Index=923`、`SCIEPortATV`、XDB GUID 和创造栏名称不变。
- 模型改为九个互不共享的 geometry：车体、车头、座椅、车把立柱、车把、四个轮胎。
- 0.8.3 将九个 geometry 挂到单个 identity `ATV` 根节点；目标 Engine 导入为 1 bone/9 meshes，避免超过 SCNET 默认七骨骼变换预算。物品栏改为枚举 `model.Meshes`。
- 所有顶点坐标烘焙为 Y_UP；每部分有法线、UV、12 个三角形。
- 32×8 PNG 含车体绿、轮胎深灰、座椅棕、金属灰四个全不透明色带；UV 取色带中心，避免缩放渗色。
- 世界碰撞盒改为 `1.7,1.15,2.1`，覆盖完整模型；旧实体模板名和持久化链未改变。
- 有驾驶者时关闭原生接地阻力，由控制器统一计算；无人时恢复原生阻力。
- 纵向积分避免松油时穿过零点抖动；横向抓地改为 `5*dt`；高速转向逐步降至 55%。
- 前进限速保持 11、倒车 4、驱动加速度 10；没有提高最高速度。
- 离地时不施加自定义刹车；0.35 秒内日志标为 `airborne-grace`，随后为 `airborne`，运动仍交给原生重力和空气阻力。
- 每辆有人驾驶的本地 ATV 最多每 5 秒记录一次诊断行。
- 一格越障仅将原生 `MaxSmoothRiseHeight` 调整为 1.05；不直接移动 Position、不写地形、不越过实体。

## 一格越障边界

原生平滑抬升会检查 terrain/moving-block 碰撞盒，用抬高下边界后的碰撞盒计算水平通过空间；顶部边界
不变，所以低矮顶棚仍会阻挡。其它实体单独用正常碰撞盒求解，因此不会作为可跨越台阶。抬升速度限制为
每秒约 4.5 格，是连续碰撞移动而非瞬移。实际一格方块、楼梯、狭窄道路和渠道 Android 数值误差仍需实测。

## Android 验收

1. 删除旧 `SCIEPort.netmod` 后安装唯一的新包，冷启动并确认版本 `0.8.3`。
2. 在新建可丢弃单人创造世界检查物品图标：车体、深色轮胎、棕色座椅、灰色车把应比例正常且没有重影。
3. 生成 ATV，环绕观察世界模型；核对与物品图标结构一致、Y 轴朝上、无透明/黑块/部件爆炸。
4. 平地从静止全油门，记录 5 秒一次的 `SCIE-Port ATV:` 日志；速度应稳定建立，不能长期停在约 1–2 格/秒。
5. 验证松油滑行、反向输入先制动再倒车、低速转向和高速转向；高速不应突然甩头。
6. 依次越过半格坡、完整一格实体方块、两格墙和低顶棚一格台阶：一格应连续抬升，两格墙/净空不足必须阻挡。
7. 对动物、玩家或其它 ATV 正面测试：不得把实体当台阶穿过；狭窄路宽不足时必须碰撞停止。
8. 驶过坑、坡顶和一格落差，确认短暂离地保持惯性且重力正常，没有飞行或空中动力。
9. 保存退出并重进，确认既有与新生成的 `SCIEPortATV` 均能恢复；检查位置、方向、骑乘和日志。

Windows 游戏运行、Android 7723、旧世界实车加载和多人同步在本轮均未执行；相应状态保持待验证或不支持。
