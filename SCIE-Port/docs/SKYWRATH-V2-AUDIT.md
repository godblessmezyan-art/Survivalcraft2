# 苍穹之怒 V2.0（雷神之锤觉醒形态）审计与验收

目标：SCNET 2.4 `x25.01.17`，Android/7723 为最终平台。状态词仅使用“已确认 / 待验证 / 不支持”。

## 实际实现

- 独立物品：`StormhammerAwakenedBlock`，ID 942，创造栏名“苍穹之怒”；ID 941 普通雷神之锤代码和行为模板保留。
- 资源：`Models/StormhammerAwakened.dae`（Y_UP、1 bone、39 meshes、1604 triangles）、`Models/ThunderSpear.dae`（Y_UP、1 bone、5 meshes、108 triangles）；觉醒主图、发光遮罩为 1024×1024，特效图 256×256，技能图标图集 2048×512。
- HUD：`StormhammerSkillHud` 只创建三个 `SkillButton`，右侧弧形坐标；大招 88 px，两个普通技能 72 px。仅手持 ID 942 时显示。雷矛按压时显示蓄力条；三按钮显示服务端确认后的冷却秒数。
- 联机：包 ID 242。普通客户端仅发送施法请求；服务端按发送者 `ComponentPlayer` 身份、实体 ID、装备、序号、冷却和大招互斥状态校验。Local/Server 执行 `AttackBody`、雷印、击退和调度；服务器把已接受、雷矛、领域、雷劫预警/落雷/结束事件广播给观察者。
- 天地异变：复用真实 `ChangeSkyColor`、`ViewFogColor` Hook，约 0.9 秒淡入、主雷后约 1.1 秒淡出；不改全局光照缓存，不写天气、时间、地形，不调用爆炸。降低频闪选项持久化为 `SCIEPortReducedLightningEffects`，降低领域/预警环粒子数。

## 三个主动技能

1. 雷狱天矛：长按至少 0.35 秒，2.2 秒满蓄；首目标按蓄力线性为 45–80 attack power；冷却 9 秒；首目标后最多 4 个额外目标，链伤害为本次首击的 62%/55%/48%/41%；每个命中目标获得 6 秒雷印。
2. 雷霆王域：跟随施法者 5 秒、半径 5；激活时对范围内生物施加一次有质量上限的冲量；立即一次并按 1 秒节拍结算 6 attack power，雷印目标为 7.2（+20%）；冷却 18 秒。
3. 万象雷劫：冷却 60 秒；目标中心由服务端射线决定，最远 24 格；半径 12 演出区内按确定性六边位置依次落下 6 道副雷（25），第 7 道主雷中心 110、外圈平滑衰减至 55；每次落雷前 0.58 秒预警；主雷后 3 秒余震阶段每秒 8。一个 Project 同时只允许一个雷劫状态。

`attack power` 进入原生 `ComponentMiner.AttackBody`，护甲、韧性及原生伤害规则仍会改变最终生命扣除，不应把上述值误称为固定 HP 扣除。

## 已确认

- `Test-Environment.ps1` 通过：目标程序集 2.4.0.0、API 1.42、SC 2.4.10.6、net472。
- Release 编译 0 警告/0 错误，DATABASE VALIDATION PASSED。
- 目标 `Engine.Media.ModelData.Load` 实际导入觉醒锤为 1/39、雷矛为 1/5；构建脚本锁定三角面、UV 基数、挂点、纹理尺寸、三个图标槽和“恰好三个按钮”。
- 包内不含永久天气/时间/地形写入路径；伤害调度在 Client 直接返回。

## 待验证

- Windows 游戏内：创造栏显示、第一/第三人称握持、掉落缩放、按钮点击/长按、三技能完整时序、天空/雾色平滑恢复。
- Android 7723：横屏分辨率/UI 缩放、移动与技能同时触控、低端机帧时间/温升、降低频闪选项效果、不同光照下材质层次。
- 多人：主机、施法客户端、旁观客户端三端冷却/伤害/雷印/领域/雷劫一致性；延迟、断线重连和两名玩家同时请求大招。

## 真机验收步骤

1. 主机与客户端安装同一 SHA-256 的 `SCIEPort.netmod`，各自新建或备份可丢弃世界；确认创造栏同时存在 ID 941 普通雷神之锤和 ID 942 苍穹之怒。
2. 分别验证库存、第一人称、第三人称、掉落物和黎明/正午/夜晚显示；录制手部穿模和画面遮挡。
3. 装备 ID 942：HUD 必须恰好三个按钮；移动触控保持按住时长按雷矛，检查 45/80 两端、最多四个额外目标、6 秒雷印；随后验证领域 5 次节拍和 +20%。
4. 三端观察雷劫：六次副雷预警后主雷，天空/雾冷色平滑恢复，3 秒余震结束；期间退出重进不得留下永久天气、时间、地形或视觉状态。
5. 使用 Android GPU profiler/系统帧率记录默认与 `SCIEPortReducedLightningEffects=true` 各 60 秒，记录机型、分辨率、平均/最低帧率、峰值温度。
