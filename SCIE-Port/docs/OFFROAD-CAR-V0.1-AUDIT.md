# 双人越野车 v0.1 技术审计

日期：2026-10-20  
目标：Survivalcraft NET 2.4 `Net_x25.01.17`，Android 7723，`net472`

## 范围与身份

本功能位于独立 `Features/OffroadVehicles/`，不修改现有 ATV 越野摩托、坦克、快艇、铁路、
植物或 Builder Assistant。物品 ID 为 925，实体名为 `SCIEPortOffroadCar`。模型和贴图均由
项目脚本从零生成，没有提取其它游戏资源。

## 尺寸规划

| 项目 | 数值（格） |
|---|---:|
| 模型范围 | X -1.15..1.15；Y 0.08..1.48；Z -1.78..1.68 |
| ComponentBody | 2.4 × 1.55 × 4.0 |
| 驾驶位 | (-0.45, 0.86, 0.18) |
| 副驾驶位 | (0.45, 0.86, 0.18) |
| 座位中心间距 | 0.90 |
| 右侧下车点 | (1.72, 0.45, 0.18) |

2.4 格宽覆盖四轮外沿并给左右各 0.05 格余量；4 格长覆盖保险杠并给前后各至少 0.2 格
余量。0.9 格座位间距大于约 0.6 格玩家宽度。下车点超过 1.2 格半车宽，同时仍接近车身。
该车明显大于双座摩托，但小于 3.6×2.1×5.9 坦克。

## 模型结构

- `New-OffroadCarAssets.ps1` 同时生成 DAE 与 PNG，结果可复现。
- 24 个独立 cuboid geometry 表示底盘、引擎盖、两座椅、椅背、四轮、保险杠、防滚架、方向盘和灯。
- 所有 geometry 挂在单一 identity `OffroadCar` node 下，目标 Engine 导入要求为 1 bone/24 meshes。
- Y_UP，单位为一游戏格；缩放与位置烘焙进顶点。
- 40×8 PNG 使用五个不透明色带，UV 取色带中心。

## 驾驶与乘坐

- 第一人进入驾驶位，第二人进入副驾驶位，第三人拒绝。
- 只有 `ComponentTwoSeatManager.Driver` 的触屏 Move 输入参与推进、倒车、制动和转向。
- 副驾驶继续由原生父 Body 跟随，可独立观察，不逐帧改写玩家 Position。
- 原生 `ComponentBody` 负责碰撞、重力、阻力和保存；驱动只在地形接地、非实体支撑和浅水条件下施力。
- `MaxSmoothRiseHeight=1.05` 复用原生连续碰撞抬升，不瞬移、不改地形。
- 深水会停止推进并让两名乘员下车。

## 联机边界

单机以及 Server 主机本地玩家驾驶代码已实现。普通客户端作为乘客只接收服务端离散座位分配，
不写车辆速度或其他玩家位置。普通客户端作为驾驶员不支持；需另行实现服务器输入、预测和纠偏。

## Android 验收清单

1. 删除旧 SCIEPort 包、安装 0.12.0、冷启动并确认能进入可丢弃创造世界。
2. 搜索“SCIE 双人越野车”，检查图标、手持与世界模型均完整可见且颜色正常。
3. 检查车辆约 2.4 格宽、4 格长，不埋地、不悬空、不超出碰撞体。
4. 第一人上车位于左侧并能前进、倒车、转向、制动；第二人位于右侧且不能控制车辆。
5. 副驾驶自由观察时不影响主驾驶方向；第三人上车应被拒绝。
6. 两人分别下车并重新上车，检查座位正确释放；深水时两人应安全下车。
7. 测试平地、斜坡、完整一格台阶、两格墙、狭路、低顶棚和其它实体；不得穿墙、飞行或瞬移。
8. 空车及双人状态分别保存退出重进、远离区块再返回，检查实体与座位无幽灵占用。
9. 双机测试主机驾驶员 + 普通客户端副驾驶；记录抖动、观察、上下车、死亡与断线行为。
