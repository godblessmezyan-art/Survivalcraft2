# 四种特色树木 0.95.0

| 树种 | 方块编号 | 成树与生成条件 | 收获 |
| --- | --- | --- | --- |
| 高棕榈 | 981 树苗、982 木、983 叶 | 16–22 格高。长直裸干、环纹树皮、伞状羽叶。暖湿河口和海岸草地，海拔接近海平面。 | 木材和树苗。可在码头栽成同等高度的地标。 |
| 椰子树 | 984 树苗、985 木、986 叶、987 椰子 | 7–11 格高。倾斜的树干、冠下三处果串。热带海滨的沙地。 | 每串至多 2 颗，可以采摘，也会自然落下。 |
| 猴面包树 | 988 树苗、989 木、990 叶、991 果 | 8–10 格高。粗干、宽冠和四处枝下果位。温暖偏干的内陆草地。 | 每处成熟果位 1 个果。可直接吃，腐坏间隔为苹果的 3.25 倍。 |
| 樱花树 | 992 树苗、993 樱木、994 粉叶 | 6–8 格高。层叠粉色树冠，四季都保持粉色。温和湿润的丘陵。 | 树苗、樱木和粉色装饰树叶。樱花树不产樱桃。 |

所有树苗都能在「自然与生物」创造栏获取。生存可砍自然或人工成树的树基取得树苗。人工栽种依树种选择沙地、草方块、泥土或耕地。具备光照和气候条件时，苗龄按原生轮询推进。水合耕地可缩短成长间隔。长成前会校验树冠、树干及树基周围的空位和加载状态，受阻时等待下一次检查。

成熟椰子从同一批果串落下。一次自然落果消耗一颗，采摘获得该果串剩余的数量。附近同时存在两颗未拾取的椰子时暂停自然落果。叶块下方有障碍时果实留在树上。果位采空后在合适气候和支撑条件下分阶段补回。猴面包果只主动采摘，同样可以再生。

自然生成接在原版地形第四阶段之后，按区块种子和栖息条件抽样。高棕榈、椰子树、猴面包树、樱花树的抽样概率分别为 19%、33%、15%、20%。每物种每区块最多一棵。旧世界探索到未生成区块时会出现新树，已探索的区块可人工种植。

原木低两位记录原生朝向，树基和自然枝条另用标志位。果位叶块记录相对树基偏移和成熟数量。搬运木材与树叶会清除这些生长标记。生长及采果通过原生地形变化与原生拾取物同步，单机或主机执行。各联机端统一使用 0.95.0。
